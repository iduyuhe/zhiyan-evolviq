# 智衍 EvolvIQ · 造船行业版介绍 ｜ 视觉设计文档（DESIGN.md）

> 风格来源：通用设计原则（产品介绍类，未命中学术 / 咨询 / 红金政务分支）。用户品牌蓝偏好 + 造船海洋工业气质 → 工业科技深蓝。

## 1. 画布与母版（三区）

- 画布：1280 × 720
- **A 标题块** 0–120px：主标题 34px 微软雅黑 Bold，左 padding 60，标题栏底色主色 `#0B2545`（封面 / 章节 / Hero 例外用全幅）。
- **B 内容区** 120–660px：540px 可用，左右 padding 60。
- **C 页脚条** 660–720px：左「智衍 EvolvIQ · 造船行业版」14px `#475569`；右 `NN / TOTAL` 14px `#475569`。全篇位置一致。
- 封面 / Hero / 结束页可自定义版式，省略 C 区或弱化。

## 2. 颜色系统（色彩池 ≤ 4 hex + 中性）

| 角色 | HEX | 用途 |
| :--- | :--- | :--- |
| 主色（深蓝） | `#0B2545` | 标题栏底、Hero 底、深色大色块（≤ 60%） |
| 辅色（品牌蓝） | `#2563EB` | 卡片头、图表系列、链接（≤ 30%） |
| 强调色（科技青） | `#06B6D4` | 焦点数字、CTA、核心标注（≤ 10%；Hero 可达 15–20%） |
| 浅底 / 中性 | `#F1F5F9` / `#FFFFFF` | 常规页背景、卡片底 |
| 文本 | `#0F172A`（主）/ `#475569`（次） | 正文、页脚 |

- 浅蓝卡底 `#EFF6FF`（辅色 8% 透明感替代）用于常规页卡片。
- **渐变方案**：标题栏 / 卡片头允许 `linear-gradient(135deg, #0B2545 0%, #2563EB 100%)`；半透明 `rgba(37,99,235,0.08)` 大面覆盖。背景图叠加 `rgba(11,37,69,0.45)` 蒙版保证白字可读。
- **色彩节奏**：Hero（01 / 10 / 12）强调色 15–20%；Supporting 强调色 ≤ 5%、辅色 ≤ 20%。禁止全篇每页比例雷同。
