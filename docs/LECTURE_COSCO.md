## 一、开场（10 分钟）— 船舶工业的特殊性

### 与汽车/电子制造的本质区别

| 维度 | 汽车制造 | 船舶制造 |
|---|---|---|
| 产品数量 | 大批量 | 单件/小批（ETO） |
| BOM 复杂度 | 千级零件 | 百万级（一条船≈10^6 零件） |
| 设计周期 | 2–3 年定型 | 每船单独设计 |
| 建造周期 | 小时级下线 | 12–36 个月 |
| 供应链 | 稳定供应商 | 全球定制采购 |
| 质量标准 | 企业标准 | DNV/BV/CCS 船检 |
| 知识形态 | 标准化作业 | 大量隐性经验（焊工/装配工） |

> **一句话**：如果能搞定船厂的数字化，其他行业都能搞定。船厂是离散制造最难攻的山头。

### 中远海运的痛点（现场互动用）

- 启东基地同时在建几艘船？——多船并行，资源冲突是常态
- 钢板利用率目前多少？——行业平均 85–88%，理论可达 92%+
- 焊接一次合格率？——影响返工成本巨大
- 进口设备到货准时率？——发动机/导航设备周期长、变数大

## 二、AI 智能体到底是什么（15 分钟）

### 核心定义

> AI Agent = 感知环境 → 理解目标 → 制定计划 → 调用工具 → 执行动作 → 校验后果

区别于传统软件：
- 传统软件：你告诉它怎么做（编程）
- AI Agent：你告诉它要什么（目标），它自己想办法

### 一个 Agent 的"大脑结构"

用智衍的 supply_chain Agent 举例：

```
输入："检查HPC-1007订单齐套率"
  ↓
理解目标 → 拆解步骤 → 调用 MCP 工具
  ↓
1. 查 BOM（get_bom_data）
2. 查库存（get_inventory）
3. 查采购订单（get_po_data）
4. 找替代料（find_alternatives）
  ↓
输出：报表 + 建议动作（准确率从 41.7% 提升到 100%）
  ↓
人在回路：高风险动作需审批
  ↓
执行后果回流 → 知识修正（做了没？效果如何？）
```

### 为什么这比"大模型问答"强？

| 场景 | 纯 LLM | AI Agent |
|---|---|---|
| "钢板库存够不够？" | 可能编造数字 | 调 WMS 实时库存 ⭐ |
| "焊接工艺怎么选？" | 给通用建议 | 查知识图谱+历史经验 |
| "排程冲突怎么办？" | 给原则 | 调 APS 系统自动优化 |
| "这条船成本超了没？" | 不知道 | 接 ERP 成本模块 ⭐ |

## 三、船舶全生命周期 AI Agent 覆盖（25 分钟）— ⭐ 重点

### 用智衍系统串讲 9 个场景

#### 3.1 设计阶段：rd_npi Agent

> 一条船的设计→工艺→BOM 传递是最容易出错的环节

Agent 做什么：
- 设计 BOM 到生产 BOM 的自动转换与差异检测
- 工艺路线自动生成与资源需求预判
- 设计变更影响分析（改一个参数，后续所有工单自动更新）

**直接价值**：设计→生产数据断链减少 80%

---

#### 3.2 分段建造排程：aps_scheduler Agent

> 船厂最大的痛：多船并行时资源怎么分

Agent 做什么：
- 自动识别分段建造瓶颈（胎位、吊车、焊工）
- 基于约束的排程优化（不是"尽量早"，而是"可行的最早"）
- 动态重排程（某分段延期时自动调整后续）

**直接价值**：船坞利用率提升 15–20%

---

#### 3.3 切割/焊接质量：quality_trace Agent

> 一条焊缝从焊接到船检的全流程可追溯

Agent 做什么：
- 焊缝 ID 自动关联（焊工→参数→NDT报告→报验状态）
- 焊接一次合格率趋势分析
- 不合格闭环（原因分析→纠正措施→效果验证）

**直接价值**：焊缝返工减少 30–50%（尤其启东海工的高强钢焊接）

---

#### 3.4 设备预测维护：pm_maintenance Agent

> 等离子切割机、龙门吊、数控弯板机——停了就是全线停

Agent 做什么：
- 设备 OEE 实时监控
- 异常振动/温度自动预警
- 维护计划动态优化

---

#### 3.5 供应链协同：supply_chain Agent

> 进口主机/辅机/钢材——任何一个晚到都影响搭载

Agent 做什么：
- 多项目物料需求合并计算
- 供应商交期预警
- 替代方案自动推荐

**实例演示**：现场输入"检查XX船钢板齐套率"→ Agent 自动分析→输出 ROI 闭环

---

#### 3.6 仓储物流：wms_logistics Agent

> 钢板堆场管理（几万吨钢板，按炉批号/材质/厚度管理）

Agent 做什么：
- 钢板智能入库定位（按材质/厚度/项目分堆）
- 按分段出库配送计划
- 设备仓储管理（进口设备库位优化）

---

#### 3.7 成本分析：cost_analysis Agent

> 单船成本核算是船厂的"账本"

Agent 做什么：
- 工时/材料/设备成本自动归集
- 成本偏差预警（与预算对比）
- 费效比分析（哪个分段最费工）

---

#### 3.8 经营驾驶舱：executive_cockpit Agent

> 管理层一眼看清"在造船舶全景"

Agent 做什么：
- 船位进度看板（每个分段现在在哪）
- 关键资源负荷（胎位/吊车/工种）
- 交付风险预警

---

#### 3.9 合规检查：compliance_q Agent

> DNV/BV/CCS——分类社规范检查

Agent 做什么：
- 自动检查报验资料完整性
- 船检意见跟踪闭环
- 规范变更影响分析

## 四、三主义方法论（20 分钟）— 独有的理论武器

### 连接主义：把船厂的隐性信号收进来

船厂到处都是数据但没人收：
- 焊接参数（电流/电压/速度）→ gateway 路
- 钢板切割计划 → system 路
- 班组长在群里说"XX 设备有点不对劲" → human 路
- 晨会决定"先做这个分段" → meeting 路

**智衍的 UNS 五路归一**就是做这件事的。

### 符号主义：把经验变成知识

老师傅的隐性经验（"这个坡口角度要留 3mm 余量"）：
- 自动捕获 → 结构化知识（KG 事实）
- 审批门确认 → 写入知识图谱
- 后续所有 Agent 都能检索到这条经验

### 行为主义：做了没？效果如何？

- 建议"换一种焊接工艺"→ 执行 → 看良率变了没
- 匹配了 → 知识置信度提升
- 不匹配 → 自动提议纠错

### 串起来讲：为什么船舶最需要这个

```
焊工经验（连接） → 知识图谱符号化（符号） → 指导下次焊接
      ↑                                        ↓
  效果验证 ← 质量数据回流（行为）
```

**离开船厂的老焊工，经验被系统留下了。新焊工上岗，直接问系统。**

## 六、与中远海工的直接结合方案（15 分钟）

### 可以立即落地的场景

| 场景 | 涉及 Agent | 预期收益 |
|---|---|---|
| 钢材齐套预警 | supply_chain + wms_logistics | 钢板短缺停产减少 50% |
| 分段建造排程 | aps_scheduler + multi-agent | 船坞周期缩短 10% |
| 焊接质量追溯 | quality_trace + compliance_q | 返工减少 30% |
| 设备预测维护 | pm_maintenance | 非计划停机减少 40% |
| 设计BOM转换 | rd_npi | 设计→生产断链减少 80% |
| 隐性经验捕获 | tacit_capture | 焊工/装配工经验数字化 |
| 多项目成本 | cost_analysis | 单船成本偏差预警 |

### 启东海工的特殊性

- **海工项目**：半潜式平台 / FPSO / 浮式风机 —— 比商船更复杂，单一项目价值几十亿
- **设计变更频繁**：海工项目业主经常改需求 → rd_npi + eco_change Agent 特别适用
- **供应链全球化**：进口设备占比高 → supply_chain 风险预警
- **高强钢焊接**：海工大量使用 E690/E700 高强钢 → quality_trace 精准追溯
