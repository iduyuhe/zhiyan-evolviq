## P0 — 现在就做（不做的话客户连试用都进不去）

### 1. 企业认证对接（1–2 ���）

**为什么卡脖子**：客户 IT 的第一句话永远是"怎么对接我们的 AD/LDAP？"

| 现状 | 目标 |
|---|---|
| API Key 鉴权（开发阶段够用） | 支持 LDAP / OAuth2 / SAML |
| 无用户概念 | 有用户 → 角色 → 租户三层 |

**最低方案**（建议先做这个）：
- 加一个 `src/runtime/auth/` 模块
- 支持 LDAP 认证（企业标配）
- 用户登录后拿 JWT Token
- 用 JWT 的 role 字段做 RBAC

**效果**：客户 IT 说"我们想试试"→你说"AD 地址给我"→半天接好。

---

### 2. 一键部署脚本（3–5 天）

**为什么卡脖子**：客户 IT 拿到源码后如果还要读半小时文档才能跑起来——就丢了

| 现状 | 目标 |
|---|---|
| `docker-compose.prod.yml` 需要手动配置 `.env` | 一个 `./install.sh` 搞定所有 |

**要做的事**：
- 写一个 `install.sh` 脚本：
  - 检测环境（Docker、端口可用性）
  - 交互式配置（域名、数据库密码、管理员账号）
  - 自动申请 Let's Encrypt 证书
  - `docker compose up -d` 一键启动
  - 输出访问地址和管理员密码

**效果**：客户 IT 拿到后在 5 分钟内看到登录页面。

## P1 — 第二步做（能缩短 POC→试点 2–4 周）

### 4. 行业知识库模板（每个行业 2–3 天）

**为什么值钱**：当前 Agent 的知识库全是半导体数据。换一个客户就要换一套数据。

| 行业 | 需要准备的 seed data |
|---|---|
| **船舶海工** | 钢板型号、焊接工艺参数、分段编码规则、船检标准 |
| **铁路通信** | SMT 物料库、IPC 标准、铁路信号产品规范 |
| **汽车零部件** | TS16949 标准、FMEA 模板、零件库 |
| **电子制造** | PCBA 物料、AOI 判图规则、ESD 标准 |

**最低方案**：
- 在 `data/seed/` 下建 `shipbuilding/`、`railway/`、`automotive/` 等目录
- 每个目录放一份 JSON 种子数据
- Agent 启动时根据 `ZHIYAN_INDUSTRY=shipbuilding` 环境变量加载对应数据

**效果**：客户说"我们是造船的" → 设一个环境变量 → Agent 就懂造船了。

---

### 5. 常见 ERP/MES 连接器模板（每个 3–5 天）

**为什么卡脖子**：Agent 再聪明，读不到客户数据就没用。

| 系统 | 当前状态 | 建议行动 |
|---|---|---|
| **SAP** | 无连接器 | 写一个 REST/SOAP 适配器（SAP RFC → REST 网关） |
| **用友 U8+ / NC** | 无连接器 | 用友开放平台 API 适配 |
| **金蝶 K/3 WISE** | 无连接器 | 金蝶 API 适配 |
| **西门子 Opcenter / MES** | 无连接器 | REST API 适配 |
| **主流 WMS（富勒/通天晓…）** | 无连接器 | WMS API 适配 |

**最低方案**：
- 在 `src/runtime/data_sources/connectors/` 下加 `sap.py`、`yonyou.py`、`kingdee.py`
- 每个连接器实现统一的 `get_bom()`、`get_inventory()`、`get_orders()` 接口
- 文档写明"对接需要的权限和接口"

**效果**：客户说"我们用 SAP" → 拿来连接器 → 配几个 endpoint → 数据就进去了。

---

### 6. Demo 数据生成器（2–3 天）

**为什么值钱**：给客户做 POC 时，不能用半导体数据演示造船场景。

**要做的事**：
- 写一个 `scripts/generate_demo_data.py --industry=shipbuilding`
- 自动生成：BOM 数据、库存数据、PO 数据、设备数据、工单数据
- 注入 UNS 事件模拟五路感知
- 生成隐性捕获测试数据

**效果**：见客户前跑一句命令→有了一个该行业的 Demo 环境。

---

### 7. 安装文档 + 用户手册（3–5 天）

**为什么卡脖子**：客户采购流程中，文档是必交的交付物

**要做的事**：
