## 三、关键设计纪律与红线遵守

- **隐私红线**：行为画像仅存于本租户、仅用于本租户推荐，**绝不跨租户聚合到个体可识别粒度**（contextvar 租户上下文 + API 级隔离测试）。
- **F4 透明标注贯穿**：每条推荐/降噪/反哺调整均附人话 reasons（如「你曾驳回此主题推荐，已下调推荐度（可撤销）」）；平台建议与真实情报相邻呈现绝不伪装。
- **单点真相**：S3-2~S3-6 全部复用 S3-1 `behavior_events` 事件池，无独立表、无双写；打分全为纯函数（可测、可回放）。
- **数据出内网红线**：客户反馈未经脱敏+审核（needs_review）绝不出内网，默认匿名。
- **白屏战略底线**：全部新前端组件在 ErrorBoundary 内，每次部署过 `smoke_check.py` 双入口门禁。
- **韧性降级**：体外感知聚合端点在源管理器/审核队列不可达时返回空结构不破管。
