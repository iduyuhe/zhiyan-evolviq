## 二、还差什么（投产缺口 ❌）

按优先级从高到低排列：

### P0 — 不给客户签合同的底线

| 缺口 | 风险 | 建议方案 |
|---|---|---|
| **企业认证/SSO** | 客户不可能给每个员工发 API Key | 对接 LDAP / AD / OAuth2（1–2 周开发） |
| **细粒度权限 RBAC** | 目前只有租户级隔离，没有操作员/工程师/管理员分级权限 | 扩展 authorization.py，加 role 字段（1 周） |
| **HTTPS/TLS** | 生产环境明文传输不安全 | Nginx 层配 Let's Encrypt（0.5 天） |
| **安装文档** | 客户 IT 无法独立部署 | 写一份完整部署指南（2 天） |

### P1 — 客户验收的门槛

| 缺口 | 风险 | 建议方案 |
|---|---|---|
| **行业连接器** | 每个客户的 ERP/MES/WMS 都不一样 | 按客户定制 DataSource 适配器（每家 1–2 周） |
| **Agent 行业知识库** | 当前 Agent 懂 SMIC 半导体，不懂造船/铁路 | 替换 seed data 为客户行业数据（每家 1 周） |
| **数据对接文档** | 客户需要知道自己系统怎么对我们 | 写 API 集成规范（3 天） |
| **监控告警** | 系统出问题了客户不知道 | 部署 Prometheus + Grafana（3 天） |
| **备份恢复策略** | 没有计划，PG/Neo4j 挂了就丢数据 | 配置定期 pg_dump + neo4j dump（1 天） |

### P2 — 规模化的基础

| 缺口 | 风险 | 建议方案 |
|---|---|---|
| **性能基准测试** | 不知道单机能承受多少 Agent 并发 | 做负载测试（1 周） |
| **日志聚合** | 排查问题全靠 docker logs | 搭 ELK 或 Loki（3 天） |
| **CI/CD 流水线** | 每次更新手动部署 | 搭 GitLab CI / GitHub Actions（2 天） |
| **版本管理** | 没有 release 流程 | 建立 semver + CHANGELOG（已有基础） |
| **移动端** | 车间工人不用电脑 | 做企业微信小程序/钉钉小程序（2–3 周） |
| **报表系统** | 客户要定期报告 | 集成 Apache Superset 或 Metabase（1 周） |

## 三、分阶段投产建议

```
阶段1: POC（现在就能做）
├─ 用时: 1 天到 1 周
├─ 交付: 客户看到 Demo 环境跑通他们的数据
├─ 门槛: ✅ 现有系统就够了
└─ 动作: 换 seed data、加行业连接器

阶段2: 试点（1-3 个月）
├─ 用时: 1-3 个月
├─ 交付: 1 条产线真实跑起来，出 ROI 数据
├─ 门槛: P0 + P1 缺口的补齐
└─ 动作: 认证/权限/文档/监控/备份 + 行业适配

阶段3: 推广（3-6 个月）
├─ 用时: 3-6 个月
├─ 交付: 全部产线接入 + 客户 IT 自主运维
├─ 门槛: P2 缺口的补齐
└─ 动作: 性能/CI/CD/日志/移动端/报表

阶段4: 规模化（6-12 个月）
├─ 用时: 6-12 个月
├─ 交付: 多基地部署 + 产业链协同
├─ 门槛: 高可用/联邦/生态
└─ 动作: 多节点/HPA/跨企业联邦
```

## 五、实话实说的结论

**能给客户讲的（诚实版）**：

> 智衍现在是 Apache 2.0 全开源，已经跑通了完整的 AI Agent 闭环——20 个 Agent、五路感知、隐性捕获、后果校验、跨企业联邦。**生产环境已经在跑了**。
>
> 但要让它在你们工厂落地，有几个条件需要满足：
>
> 1. **你们的 IT 系统有开放接口**（REST API / OPC-UA / MQTT）—— Agent 需要读数据
> 2. **需要 1-2 周做行业适配**——把 Agent 的知识库从半导体换成你们的行业
> 3. **需要配上企业认证和权限管理**——目前是 API Key 级别，需要对接你们的 AD/LDAP
> 4. **建议分阶段走**：先 1 条产线 POC → 验证 ROI → 再推广

**不建议说的**：
- 不要承诺"开箱即用"——当前状态对懂 Docker 的团队是开箱即用，对传统制造企业的 IT 还需要指导
- 不要承诺"零定制"——每个客户的 ERP/MES 不一样，数据连接器总要适配一次
- 不要承诺"SLA 99.9%"——目前单节点部署，没有高可用，小规模试点没问题，生产还需要加固
