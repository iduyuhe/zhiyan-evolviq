# 智衍 EvolvIQ · 经营智能成熟度模型（全息孪生社会）

> **承接文档**：`PRODUCT_LANDING_PLAN.md`（产品版本路线图）+ `STRATEGY_SYSTEM_ROADMAP.md`（战略）+ `HOLOGRAPHIC_INFO_SOURCE_ARCHITECTURE.md`（架构）
> **本模型回答**：产品路线图回答"我们交付什么"，本模型回答"客户/系统的经营智能处于什么水平"。它是销售与陪跑的**诊断工具**——给客户定位 Level → 推荐对应版本跃迁；也是北极星指标（实时化率）的分级刻度。
> **核心命题**：制造企业的经营智能不是"上没上 AI"，而是沿"全息孪生社会"框架逐级长大的连续谱。Level 之间靠补最撬动全局的一环跃迁（呼应有机落实节奏）。

# 0. 为什么需要成熟度模型

| 视角 | 路线图（已有） | 成熟度模型（本文件） |
|---|---|---|
| 主语 | 我们（供给方） | 客户/系统（采用方） |
| 问题 | 下一版交付什么？ | 客户现在在哪、差哪一步？ |
| 用法 | 工程排期 | 销售诊断 / 陪跑目标 / 客户自评 |

二者对偶：**版本节奏 = 跃迁的供给，成熟度 = 跃迁的状态**。客户从 L1 升 L2，需要的正是 v21.0；从 L3 升 L4，需要的正是 v22.0。

# 2. 六级成熟度定义

## L0 · 滞后账本态（Legacy Ledger）
- **特征**：纯 ERP/MES 记录，无孪生、无 agent；决策靠人翻滞后账本。
- **关键能力**：结构化业务数据电子化（订单/库存/财务可查）。
- **实时化率**：≈ 0%。
- **对应版本**：无（客户起点）。
- **跃迁门槛→L1**：建单域可视化/大屏，让状态"看得见"。
- **典型陷阱**：以为买 BI 大屏就是数字化；仍滞后、仍无推理。

## L1 · 单点可视态（Point Twin）
- **特征**：某域有几何孪生/大屏（死镜像），无 agent 实时推理。
- **关键能力**：单域状态实时呈现；数据直采（网关/MQTT）。
- **实时化率**：< 10%。
- **对应版本**：v20.6 部分能力可作起点（twin_feed 状态层）。
- **跃迁门槛→L2**：让至少一个 agent 基于实时孪生出可执行建议（阶段 1 下半场）。
- **典型陷阱**："数字僵尸"——漂亮模型不反作用、不推理。

## L2 · 实时孪生引擎态（Live Twin Engine）
- **特征**：网关流驱动单域 agent 实时决策；孪生体是活 agent 非镜像。
- **关键能力**：twin_feed 状态上行 + agent 消费 twin_context 出实时结论 + 人审闸门。
- **实时化率**：10%–40%。
- **对应版本**：**v21.0**（实时孪生引擎）。
- **跃迁门槛→L3**：把人/社交/会议/协作的隐性信号也接进来并锚定。
- **典型陷阱**：只接设备不接人，决策仍缺隐性知识（滑稽感半消）。

## L3 · 综合集成态（Integrated / Tacit Capture）
- **特征**：五路感知归一（含 collab）；隐性知识被抽取即锚定进经验库。
- **关键能力**：UNS 五路适配器 + 抽取即锚定 + HITL 审批门；差异化壁垒成形。
- **实时化率**：40%–60%。
- **对应版本**：**v21.5**（隐性捕获）。
- **跃迁门槛→L4**：让执行后果显式回流认知层，闭合蓝弧。
- **典型陷阱**：噪声拦截过度，真知被误杀（靠人审通过率监控）。

## L4 · 蓝弧闭环态（Closed-Loop）
- **特征**：执行后果显式回流本体/经验库；行为主义校验修正符号与连接。
- **关键能力**：信息补录蓝弧 + 后果校验；三主义活循环真转。
- **实时化率**：60%–85%。
- **对应版本**：**v22.0**（蓝弧闭环）。
- **跃迁门槛→L5**：元层治理成熟（Ontology 对外 + holon 治理面板 + 自进化广样本）。
- **典型陷阱**：回灌污染真相源（靠 §3.7 纪律兜底）。

## L5 · 全息孪生社会态（Holographic Twin Society）
- **特征**：人/机/料/法/环全要素自治协作；元 holon 治理；系统自成长。
- **关键能力**：薄/厚 holon 全自治 + 自进化成熟（P2 广样本反思）+ Ontology 对外命名。
- **实时化率**：> 85%（稳态目标）。
- **对应版本**：**v22.5 + v23.0**（本体升格 + 自进化成熟）。
- **跃迁门槛→**：无（持续自进化）；进入"越用越聪明"飞轮。
- **典型陷阱**：孪生层脱离物理（靠蓝弧保险丝兜底）。

# 3. 成熟度矩阵（六维 × 六级，CMMI 风格）

图例：● 成熟（该级已稳固）　◐ 过渡（部分具备）　○ 缺失

| 维度 \ Level | L0 | L1 | L2 | L3 | L4 | L5 |
|---|---|---|---|---|---|---|
| D1 感知广度 | ○ | ◐ | ◐ | ● | ● | ● |
| D2 孪生深度 | ○ | ◐ | ● | ● | ● | ● |
| D3 决策实时性 | ○ | ◐ | ● | ● | ● | ● |
| D4 闭环完整性 | ○ | ○ | ◐ | ◐ | ● | ● |
| D5 自治与治理 | ○ | ◐ | ◐ | ● | ● | ● |
| D6 自进化能力 | ○ | ○ | ○ | ◐ | ◐ | ● |
| D7 原生度 | ○ | ○ | ◐ | ◐ | ◐ | ● |

> 读法：L2 列 D1/D4/D6 仍 ◐/○，说明"实时引擎"期感知与闭环尚未全熟——正对应 v21.0 只做单域实时、隐性捕获与蓝弧留待后续版本。矩阵直观暴露"木桶短板"，指导跃迁优先级。
>
> **⚠️ 防误判（原生度视角）**：D7 行揭示"级别高≠领先"。巨头（如西门子 L4–L5）在此维仅为 ◐——其成熟度是 **retrofit（旧底座改装）** 出来的，含 legacy 组织惯性、硬件栈锁定、数据孤岛包袱；智衍虽处 L1–L2，但此维为 ●（**born-native**，从设计第一天按 holonic/三主义/五路感知写，无 legacy）。评估竞争时须 **双维同看**：单看 Level 会误判"我们差三代想错了"，看 D7 才知差距主要是资金/数据飞轮/认证——这些可用"轻量 + 开源 + 联盟陪跑"绕开，而非硬碰巨头主场。

# 5. 自评估清单（销售/陪跑现场用）

客户逐项勾选，命中最高连续 Level 即为当前成熟度：

- [ ] 有结构化 ERP/MES 数据（≥ L0）
- [ ] 至少一域状态实时可见（≥ L1）
- [ ] 某 agent 基于实时数据给出可执行建议且人终审（≥ L2）
- [ ] 人/社交/会议信号被采集并锚定进知识库（≥ L3）
- [ ] 执行后果自动回流并修正后续策略（≥ L4）
- [ ] 全要素自治协作 + 系统自进化无人工干预仍稳健（≥ L5）

> **原生度附加透镜（独立于 Level）**：勾完 Level 后另评 D7——核心架构是否为 AI 原生（新增能力无需背负 legacy 约束）。即便某客户/对手等级高（如 L4 retrofit），若 D7 仅 ◐，其"长大"被 legacy 拖累、二次开发/迁移成本高，反不如 born-native 的 L2。本模型因此把"级别"与"原生度"解耦，避免被表面级别迷惑。

# 6. 与路线图 / 北极星的关系

- **实时化率 = 成熟度的量化代理**：L0≈0% → L5>85%，把"长大"变成可测数字。
- **版本节奏 = 跃迁的供给**：v21.0 供给 L1→L2，v22.0 供给 L3→L4，一一对应。
- **有机落实的统一语言**：成熟度模型让"每次只补最撬动全局一环"有了客户侧刻度——先补木桶最短板（见 §3 矩阵），而非堆功能。
- **原生度解耦（防被现象迷惑）**：成熟度 Level 度量"长大到哪"，原生度 D7 度量"长大得干不干净"。二者独立——巨头高 Level 含 retrofit 包袱，智衍低 Level 却 born-native。评估竞争与客户时务必双维同看（见 §3 D7 行注）。
