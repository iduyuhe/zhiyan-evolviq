## 一、开场（10 分钟）— 制造业正在经历什么

### 问听众三个问题（互动收效快）

1. **你的 MES/ERP 上了多久？** —— 通常 3–5 年
2. **现在数据能实时指导决策吗？** —— 通常不能（Dashboard 滞后 24h+）
3. **老师傅的经验有没有被系统化？** —— 通常没有（人走了经验就没了）

### 核心观点抛出

> 制造业过去 30 年的信息化，本质上是在做"数据沉淀"——把纸上的东西搬进电脑里。
> 但沉淀≠流动，数据能看≠数据能决策。
> **AI 智能体时代，核心命题从"怎么存数据"变成了"怎么让数据自己决策"。**

### 引出案例：智衍 EvolvIQ

一个 Apache 2.0 全开源的工业智能体互联平台，20 个垂直 Agent、65 个 MCP 工具。  
今天用它做"活化石"，看看 AI 智能体时代制造到底长什么样。

## 二、什么是一个"AI Agent"（15 分钟）— 讲透概念

### 不是 Chatbot，是"数字员工"

| 特征 | Chatbot | AI Agent |
|---|---|---|
| 决策方式 | 问→答 | 感知→分析→决策→执行→校验 |
| 环境交互 | 无 | 读 MES/ERP/PLC/OPC-UA |
| 记忆 | 无 | 有经验库，跨对话积累 |
| 工具使用 | 无 | 调用 65 个 MCP 工具 |
| 自主程度 | 被动响应 | 授权范围内自主执行 |

### 智衍 20 个 Agent 一图展示

用下面这张表讲：

| 产线层 | 管理层 | 供应链层 |
|---|---|---|
| smt_changeover（换线优化） | aps_scheduler（排程） | supply_chain（齐套） |
| aoi_judge（AOI判图） | cost_analysis（成本） | wms_logistics（仓储） |
| oee_optimizer（OEE提升） | energy_carbon（能耗碳排） | demand_order（需求） |
| pm_maintenance（预防维护） | executive_cockpit（经营驾驶舱） | procurement_manage（采购） |
| quality_trace（质量追溯） | compliance_q（合规） | rd_npi（新品导入） |
| dfm_check（可制造性） | ipc_standard（IPC标准） | bom_selector（BOM选型） |
| eco_change（工程变更） | | |

**对上海铁路通信最相关的 6 个 Agent**：
- `smt_changeover` → SMT 换线效率（多品种小批量痛点）
- `quality_trace` → 通信板卡全流程追溯（铁路安全要求）
- `ipc_standard` → IPC-A-610 电子组装标准合规
- `pm_maintenance` → 贴片机、波峰焊设备预测维护
- `supply_chain` → 电子物料齐套率提升（芯片/电阻/电容短缺场景）
- `tacit_capture` → 隐性知识捕获（技工操作经验数字化）

## 三、AI Agent 在制造中怎么工作（25 分钟）— 三主义方法论

### ⭐ 这是最核心的论点，建议重点讲

> 单一 AI 范式解决不了工业问题。需要**三个主义合一**。

### 1. 连接主义 — 信号感知
工厂里到处都是数据：设备振动、温湿度、OEE、交期预警、老师傅在群里说的一句话……
但它们是**碎片化的隐性信号**。连接主义做的就是"把所有信号用一种语言收进来"。

**智衍实现**：UNS 五路归一

| 感知路 | 对应工厂场景 |
|---|---|
| gateway | SMT 贴片机实时状态、回流焊温度曲线 |
| system | ERP 工单、MES 报工、WMS 库存 |
| human | 车间主任在企微群发的"××物料可能不够" |
| social | 行业芯片产能动态 |
| meeting/collab | 晨会纪要中的决策理由 |

### 2. 符号主义 — 知识锚定
信号必须有结构才能被推理。符号主义就是把隐性信号变成"实体-关系-实体"的结构化知识。

**智衍实现**：知识图谱 + 本体自生长
- 隐性信号 → 自动抽取 → KG 事实 draft → 审批门 → 写入图谱
- 本体自动发现新实体类型（从 EMP: 前缀推断出"员工"类型）

### 3. 行为主义 — 后果校验
决策好不好，看结果。行为主义就是"执行→看后果→修正知识→下次更好"。

**智衍实现**：蓝弧闭环
- Agent 执行动作 → 预期后果注册 → 真实后果回流
- 匹配→知识置信度提升；不匹配→自动提议纠错

### 三主义的活循环

```
隐性信号（连接主义）→ 知识锚定（符号主义） → 执行（Agent）
     ↑                                          ↓
     经验沉淀 ← 后果校验 ← 结果反馈（行为主义）
```

## 五、智衍与上海铁路通信的深度结合（15 分钟）

### 可以直接落地的场景

| 场景 | 涉及 Agent | 预期效果 |
|---|---|---|
| SMT 换线优化 | smt_changeover | 换线时间缩短 30%+ |
| 电子物料齐套预警 | supply_chain + wms_logistics | 缺料停产风险下降 50%+ |
| DFM 可制造性检查 | dfm_check | 设计问题在试产前发现，减少改模成本 |
| 质量追溯 + IPC 合规 | quality_trace + ipc_standard | 全流程追溯，满足 SIL 审计要求 |
| 设备预测维护 | pm_maintenance + oee_optimizer | 非计划停机减少 40% |
| 隐性知识数字化 | tacit_capture | 经验丰富的技工知识自动沉淀 |

### 铁路通信的特殊性：安全关键系统

铁路信号产品属于 SIL（Safety Integrity Level）认证产品，意味着：
- 任何 AI 决策不能是黑箱 → 智衍的"审批门"机制契合
- 知识图谱可审计 → 每一条 KG 事实都有来源
- 人在回路 → 高风险动作必须人工审批
- 后果闭环 → 每个决策都可追踪执行效果

## 六、成熟度模型：评估你们在哪（10 分钟）

用智衍的 L0–L5 三轴模型，让听众自己评估所在位置：

| 级别 | 实时化率 | AI 原生度 | 自主可控度 | 典型特征 |
|---|---|---|---|---|
| L0 | <10% | 无 | 外资闭源 | Excel + 纸质流转 |
| L1 | 10–25% | AI 辅助 | 国产化部分替代 | 上了 MES，但数据滞后 |
| L2 | 25–50% | AI+ | 信创半开放 | 部分流程自动化 |
| L3 | 50–70% | AI-native | 全开源可用 | Agent 自主决策 + 人在回路 |
| L4 | 70–85% | 自进化 | 全开源标准化 | 系统越用越聪明 |
| L5 | 85%+ | 自进化联邦 | 产业链联邦 | 智能体跨企业协同 |

## 七、开源开放 vs 商业锁定的战略选择（10 分钟）

### 全球二十强 CCI 竞争力图谱

讲这张表的核心结论：

> - 智衍当前 CCI=0.258（二十强垫底）——实事求是不自夸
> - 智衍天花板 CCI=0.657（第一梯队）——因为 A(自主)=1.0, S(原生)=1.0
> - 西门子 CCI=0.438，天花板仅 0.586 —— retrofit 封顶
> - Palantir 被 A=0.05 钉在 0.512 —— AI-native 也救不了主权封顶

**结论**：在自主可控成为硬约束的今天，"全开源 + born-native"不是可选项，是结构性优势。

### Apache 2.0 意味着什么

- 代码随便看、随便改、随便部署
- 不被厂商锁定
- 可做信创适配
- 没有"授权费越用越贵"的陷阱

## 八、互动 Q&A 与结语（15 分钟）

### 预期会被问到的问题准备

| 问 | 答 |
|---|---|
| "AI Agent 会不会出错？" | 会，所以有"审批门 + 蓝弧闭环"——出错了自动纠正并沉淀经验 |
| "上这套系统要多少钱？" | 开源版免费，部署需服务器资源（最低 4C8G + Docker） |
| "跟我们现有 ERP 冲突吗？" | 不冲突——路线 A：不砸 ERP，在其上叠加实时决策脑 |
| "老师傅经验怎么数字化？" | 通过企微/钉钉/会议自动捕获，系统提炼成 KG 事实，审批后生效 |

> 上 ERP 是让企业"知道自己有什么"。
> 上 AI Agent 是让企业"自己就知道该怎么做"。
> 制造业的未来，不是更大更贵的软件，而是**会自己长的智能体**。
> 智衍告诉你——这不只是概念，代码已经开源在生产环境跑着了。
