## 〇、战略一句话主张（总纲之纲）

**智衍不做"又一个 ERP"，也不做"挂在 ERP 旁边的聊天框"；我们做企业经营的「实时决策脑 + 全息真相源」——客户不用砸掉现有 ERP/MES，就能获得一个会自己长知识、能消化现场隐性信号、且把 ERP 当执行回写通道的原生智能体系统。**

差异化的根不在"接不接 ERP"，而在**真相源的位置**与**自主可控的程度**：
- 真相源 = 三主义合一的活循环（连接抽取 → 符号治理 → 行为校验），ERP 退居"执行回写 + 审计"。
- 自主可控 = Apache-2.0 全开源（A=1.0），客户脱绑巨头锁定——这是平权时代最锐的护城河楔子。

## 四、成熟度与竞争力量化结论（浓缩）

### 4.1 成熟度模型三轴（MATURITY_MODEL v3.0）
- **X 轴 成熟度 L0–L5**：实时化率 0% → 85%+（感知/认知/决策/执行/自适应五级）。
- **Y 轴 演进阶段**：AI（ retrofit 装壳）→ AI+（局部自进化）→ AI-native（born-native，天花板 L5）。
- **Z 轴 自主可控度**：闭源外资 ↔ 信创半开放 ↔ Apache 全开源（=客户自由度）。
- 维度 D1–D10：D8 真相源性质、D9 底座锁定度、D10 自主可控度 是巨头系统性短板；智衍短板在 D3（数据飞轮）/ D6（认证）。

### 4.2 二十强 CCI（COMPETITIVENESS_MATURITY_SYNTHESIS，分层封顶、数字自洽）
```
CCI(t) = M(t) × ( α·S(t) + β·A(t) + γ·N(t) )      α=0.30, β=0.35, γ=0.35
```
| 量 | 怎么读 | 智衍位置 |
|---|---|---|
| **自主可控 A** | 气泡颜色 / 雷达 A 轴 | **A=1.00 顶满（深蓝）**；外资巨头 A≤0.20 系统性塌方 |
| **发展前景 S** | Y 轴原生度 + 轨迹斜率 | S=1.00 顶满；轨迹最陡，约第 2.4 年反超西门子 |
| **竞争力 CCI** | 气泡大小 + 绝对值 + 轨迹高度 | 当前 0.258（二十强倒数第二，诚实）；天花板 **0.657 居首梯队** |

**排名（诚实 + 有力）**
- 当前：微软(0.476) > NVIDIA(0.466) > 西门子(0.438) > … > 智衍(0.258，倒数第二)。
- 天花板：智衍(0.657) > 微软(0.647) > 阿里(0.636) > 美的(0.619) > NVIDIA(0.618) > 华为(0.617)。
- **核心**：当前不是最强，但天花板超过所有巨头（含用友/金蝶/Palantir）——约第 2.4 年反超。真正天花板对手是横向 AI 主权力量（微软/华为/阿里/腾讯/美的），非传统工业/ERP 厂（被 A+S 双重封顶 <0.59）。

### 4.3 自评估三轴（智衍当下）
- **范式 A**：全息孪生社会 —— born-native，无 legacy，占满三主义闭环（领先）。
- **成熟度 B**：M≈0.35（L2 边沿）—— 骨架 70% 已具备（v20.5/v20.6），缺口是"接线 + 扩面"。
- **自主可控 C**：A=1.00 —— Apache-2.0 全开源，结构性最锐。

## 六、对外一页纸（客户 / 投资人 / 联盟版）

> 用途：15 秒讲清我们是谁、为什么现在、为什么能赢。不自夸当下，敢言天花板。

**智衍工业智能体互联平台（EvolvIQ）—— 不砸 ERP，给企业装一个会自己长的实时决策脑。**

- **痛点**：企业 AI 落地最深的坑是"快决策脑读滞后账本"——ERP 是裁剪过、T+1、装不下隐性信号的旧账，真相源错位。
- **我们做**：在客户现有 ERP/MES 之上叠加「实时决策脑 + 全息真相源」。五路感知（设备/系统/人/社交/会议协作）归一，三主义活循环让知识自生长，ERP 只做执行回写。
- **为什么现在**：2026 是工业 AI 原生拐点；巨头（西门子/美的）的同款方向已被验证，但多为 retrofit 旧底座改装、且闭源锁定客户。
- **为什么是我们（护城河）**：① **born-native** 无 legacy，迭代快；② **Apache-2.0 全开源**，客户自主可控（巨头闭源 A≤0.20，我们 A=1.0）；③ **六柱开放网络飞轮**——用开放换引力、用引力换标准、用标准换主权。
- **诚实定位**：当前竞争力仍在爬坡（二十强倒数第二），但天花板居首梯队，约第 2.4 年反超巨头——因为我们占满"全开源 + 原生 + 工业 agent 专精"的结构性空档。
- **首客场景**：轻量经营孪生看板（供应链/能耗/排产的可视 + 建议），不碰巨头硬件/功能安全认证级硬仗。
