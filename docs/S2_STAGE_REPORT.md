## 三、关键设计纪律与红线遵守

- **F4 可信治理**：平台建议走独立 UNS 通道 `platform_insight` + `credibility="platform"`，与 `environment` 真实情报严格分离；前端蓝色左边框卡片 + 「💡 来自智衍平台的建议」徽标，相邻呈现绝不伪装。
- **白屏战略底线**：所有 S2 新前端组件在 `ErrorBoundary` 内；每次部署必过 `smoke_check.py`，未过即回滚。
- **内容级幂等去重**：去重键 = `tenant_id|source|template_key|title`，同一真实情报被重复拉取不重复生成平台建议。
- **额度豁免**：平台建议合并不计入 `/feed` 外部信号日额度（usage_meter 仅计量 kind=intelligence）。
- **共享池语义**：`platform_insights` 表 `tenant_id` 固定 `"default"`，不含租户私有信息，对所有租户可见，与「抓取共享、语义隔离」两层制一致。
