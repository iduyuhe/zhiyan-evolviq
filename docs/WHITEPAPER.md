## 摘要

中国制造正面临一个结构性困境：花十年上 ERP/MES，刚上线就已滞后于业务变化——数据不是在"制造决策脑"，而是在"制造历史记录仪"。与此同时，AI Agent、数字孪生、自主可控等概念迭出，但碎片化部署让企业陷入"新 IT 孤岛"。

**智衍 EvolvIQ** 选择了一条不同的路：不推倒客户现有的 ERP/MES，而是在其上叠加一个**实时决策脑 + 全息真相源**——作为一个"原生赋能者"，让企业在不砸旧系统的前提下，实时感知、实时决策、实时执行。这不是 ERP 的替代品，而是 ERP 应现代智能制造的进化方向。

本白皮书完整阐述智衍的战略定位、哲学基础、体系架构、成熟度模型、竞争力图谱、产品路线图与开放生态战略，为工业智能体互联平台的规模化落地提供完整的认知框架。

## 1. 问题：制造的"三座大山"

### 1.1 数据沉淀而不流动

中国制造企业的信息化历程，大体上是一部"数据沉淀史"：ERP 沉淀交易数据、MES 沉淀过程数据、PLM 沉淀产品数据、WMS 沉淀物流数据……但绝大多数企业走到"数据能看"就停下了，数据并没有**流动**起来——形成跨系统的决策循环。

结果是：**数据是历史的，决策是滞后的**。管理者看到的 Dashboard 是昨天 18:00 的数据，而今天 09:00 的产线异常已经发生。

### 1.2 信息孤岛到新 IT 孤岛

"上 ERP"曾是打破信息孤岛的答案，但三十年实践证明：ERP 本身成了最大的孤岛——它统一了财务流程，却无法统一工厂现场；它定义了"应该怎么做"，却不知道"实际上发生了什么"。

更危险的是，当 AI Agent、数字孪生、IoT 平台等新技术涌入时，企业不在"整合旧孤岛"，而是在"制造新孤岛"。每上一个系统就多一套数据源、多一个登录入口、多一种数据语言。

### 1.3 自主可控的结构性困境

地缘政治与供应链安全将"自主可控"推到了企业决策的前台。但市场上绝大多数工业软件平台隶属于**外资闭源厂商**——西门子（MindSphere）、SAP（BTP）、Oracle、达索……它们的商业模式本质上决定了：客户数据在它们的云上，客户逻辑跑在它们的引擎里，客户被"锁定"在它们的生态中。

这不是"技术问题"，而是**结构性问题**——深嵌在封闭商业模式的基因里，无法通过产品更新解决。

## 2. 答案：路线 A 原生赋能者

### 2.1 三条路线的选择

面对"三座大山"，行业存在三条路线：

| 路线 | 主张 | 问题 |
| --- | --- | --- |
| **A 原生赋能者**（智衍选择） | 不推倒 ERP/MES，叠加实时决策脑 + 全息真相源；ERP 退居执行回写 + 审计 | 需与存量系统协作，对认知架构要求极高 |
| B 推倒账本 | 用新平台替代 ERP/MES | 企业迁移成本不可承受，周期太长 |
| C 混合渐进 | 部分推倒、部分叠加 | 最终仍归到 A 或 B |

**智衍选择路线 A**，核心逻辑是：客户的钱应该花在"决策能力"而非"数据迁徙"上。ERP 账本功能是可靠的工业基石，它的问题不是"错了"，而是"不够快"——智衍给的是**实时的决策脑**，而非另一个账本。

### 2.2 "原生"的收敛定义

"原生赋能者"不是一句口号，而是三个收敛约束：

1. **原生决策权**：数据在哪里、就地在哪决策，绝不为了统一数据结构而强制数据搬迁。Agent 在 MES 端感知、在 OPC-UA 通道推理、在 ERP 接口执行——但决策逻辑跑在智衍平台上。
2. **原生全息沉淀权**：每个实体（设备 / 产线 / 订单 / 人）都有一条"全息记录"——从 OEE 到能耗、从交期到碳排、从显性操作到隐性判断，所有与该实体相关的信号都自动归集、结构化沉淀。这是"第一真相源"的物理解耦：不是替代 ERP 账本，而是在账本之外构建全息层。
3. **非原生账本**：智衍不做账本。财务、库存、BOM 等"账本类"功能由现有 ERP/MES 负责，智衍只"读"不"写"这些核心账本数据。事实锚点铁律确保了这条线的刚性。

### 2.3 竞争站位

| 维度 | Palantir | 传统 ERP 厂商 | AI-native 平台 | 工业龙虾 | **智衍 EvolvIQ** |
| --- | --- | --- | --- | --- | --- |
| **核心范式** | 静态符号主义（Ontology + 人工建立） | 结构化数据驱动（关系型） | Agent-native（无符号锚定） | 连接主义优先（设备互联） | **三主义一体（符号 + 连接 + 行为）** |
| **进化能力** | ⬜ 需 FDE 驻场，不会自己长 | ⬜ 版本升级驱动 | ⬜ 模型热更新 | ⬜ 协议扩展 | ✅ **自进化循环** |
| **自主可控** | ❌ 闭源外资 | ❌ 闭源外资 | ❌ 多闭源 | ⬜ 部分开源 | ✅ **Apache 2.0 全开源** |
| **隐性感知** | ❌ 仅显性数据 | ❌ 仅结构化 | ✅ 力 | ⬜ 设备级 | ✅ **五路感知全部覆盖** |
| **护城河** | 治理合规 | 客户存量 | 模型能力 | 设备连接 | **六柱开放网络飞轮** |

**结论**：智衍占满三块关键空地——(a) 路线 A 原生赋能者（不砸 ERP）、(b) 三主义一体活循环（符号锚定 + 连接抽取 + 行为校验）、(c) Apache 全开源主权架构。这三点任何一个对手要补的成本都极高，且三者合一的闭环效应形成结构性壁垒。

## 3. 哲学基础：三主义一体的活循环

### 3.1 知识论的三根支柱

智衍的认知架构根植于一个简单但深刻的知识论洞察：**任何单一知识范式都不足以支撑工业决策**。

| 主义 | 认知模式 | 在智衍中的落点 | 传统案例 |
| --- | --- | --- | --- |
| **符号主义**（Symbolism） | 世界 = 符号 + 规则；推理 = 符号操作 | 知识图谱（Ontology）、规则引擎、审批门、Prompt 模板 | 专家系统、知识图谱 |
| **连接主义**（Connectionism） | 世界 = 信号 + 权重；推理 = 模式匹配 | UNS 五路感知、隐性信号抽取、经验学习、MCP 联邦 | 神经网络、深度学习 |
| **行为主义**（Behaviorism） | 世界 = 状态 + 动作；推理 = 后果反馈 | Agent 执行后果校验、置信度调整、纠错提议 | 强化学习、反馈循环 |

### 3.2 活循环：三主义不是并列的三块

关键不在于"三种知识并存"，而在于**三者形成一个活的闭环**：

```
连接主义（UNS 隐性信号抽取）
        ↓
   抽取即锚定
        ↓
符号主义（知识图谱 Ontology + 审批门）
        ↓
   决策执行（Agent 动作）
        ↓
行为主义（后果校验 + 置信度修正）
        ↓
   回流修正符号（纠错 / 验证）
        ↓
        ↺ （回到连接主义捕获下一轮隐性信号）
```

这个循环的每一步都在**自动进行**——不需要人画 Ontology、不需要人定规则、不需要人 feed 数据。智衍的"活循环"就是它自己会长的引擎。

### 3.3 本体（Ontology/符号主义）的定位

本体/知识图谱（符号主义）是智衍三主义中的**一根支柱**——不是全部，不是平台名称。我们的平台是**智衍工业智能体互联平台**，内置了三主义一体架构。

这与 Palantir 的本质区别：
- **Palantir** 以静态 Ontology 为核心（纯符号主义），需 FDE（前线工程师）驻场建立和维护；其 Ontology 受限于符号主义单范式——不会自己长。
- **智衍** 以三主义一体活循环为核心，符号/连接/行为三者自动闭环——不是在"抄 Palantir"，而是站在它缺的那块完整范式之上。符号主义是其中内置的一部分，不向下看齐。

## 4. 架构：全息真相源与五路感知

### 4.1 第一真相源

智衍定义"第一真相源"为企业运行的**全息活数据体**——不是数据库快照，不是报表导出，而是实时、完整、可溯源的信号流。

第一真相源 = **三主义（符号/连接/行为）合一的活循环**。知识图谱仅是这个循环的**可审计快照**，而非真相源本身。防止"图谱 = 真相源"的符号主义偏见。

### 4.2 五路感知

智衍的感知层覆盖工业决策所需的全部信号来源：

| # | 感知路 | 示例源 | 类型 | 传统 ERP 覆盖 |
| --- | --- | --- | --- | --- |
| ① | **网关**（Gateway） | OPC-UA / Modbus / MQTT / IPC-CFX | 设备实时状态、传感器 | ❌ |
| ② | **系统**（System） | ERP / MES / PLM / WMS REST | 业务事件、订单状态 | ✅（部分） |
| ③ | **人**（Human） | 微信/企微/钉钉消息 | 隐性判断、经验表达 | ❌ |
| ④ | **社交**（Social） | 行业动态、社区讨论 | 趋势信号、群体认知 | ❌ |
| ⑤ | **会议/协作**（Meeting/Collab） | 会议纪要、协作消息 | 决策依据、团队共识 | ❌ |

**关键洞察**：③④⑤ 是隐性信号的主出口，也恰好是传统 ERP **零覆盖**的区域——这是智衍的楔子定位点。

### 4.3 四协议网关

智衍的网关层原生支持四种工业协议：

- **Modbus RTU/TCP**：存量 PLC 兼容
- **MQTT**：IoT 原生协议
- **OPC-UA**：工业 4.0 标准协议
- **IPC-CFX**：电子制造行业协议（SMT 产线）

**韧性降级铁律**：任何外部依赖（PostgreSQL / Neo4j / OPC-UA / AMQP）不可达时自动回退（SQLite / 内存图 / simulated），绝不阻断启动或执行。

### 4.4 统一事件总线（UNS）

五路感知同 schema 归一入轻量 UNS（Unified Namespace）：

```
channel  : gateway | system | human | social | meeting | collab
source   : opcua://line-3 | erp://sap/mm | wecom://group-x | collab://community-equipment
type     : sensor_reading | business_event | tacit_judgment | decision_rationale | collab_message
payload  : {...结构化字段...}
entities : [LINE:3, DEV:hyd-105, MAT:CAP-001, SUP:A, EMP:zhang]
```

其中 `collab` 源允许设备作为**一等参与者**进入协作话题——这是灵感来自工业龙虾项目：机器不只是被监控的对象，而是智能体的对等协作方。

## 6. 成熟度模型：L0–L5 三轴评估体系

### 6.1 评估框架

智衍的成熟度模型（v3.0）以**三轴**评估一个组织的工业智能体互联水平：

| 轴 | 维度 | L0 | L1 | L2 | L3 | L4 | L5 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **X** | 实时化率 | 0–10% | 10–25% | 25–50% | 50–70% | 70–85% | 85%+ |
| **Y** | AI 原生度 | 无 | AI 辅助 | AI+ | AI-native |
| **Z** | 自主可控度 | 外资闭源 | 闭源本国 | 信创半开放 | 全开源（Apache） |

**X·Y·Z 三轴的关系**不是独立的——它们互相牵制：
- X（实时化率）是基础：没有数据流，AI 没有燃料
- Y（AI 原生度）是天花板：retrofit 的 AI 有结构性上限
- Z（自主可控度）是**乘法项**：闭源外资被 A∩=0.20 钉死，全开源可达 1.0

### 6.2 六维原生度 D7

除三轴外，模型引入"原生度 D7"作为 AI 原生度的子维度——判断一个平台究竟是"真原生"还是"旧酒新瓶"：

1. **原生架构**：模块可插拔、热插拔
2. **原生数据**：数据一旦产生即被消费
3. **原生智能**：Agent 自主感知 + 自主决策
4. **原生实时**：事件驱动而非批处理
5. **原生网络**：不是 API 集成，而是协议级互联
6. **原生治理**：Open Core + 社区治理
7. **原生主权**：Apache 2.0 许可 + 无需任何商业授权即可跑满能力

**关键区分**：L4 与 L5 的分界是"原生度 D7 + 自进化"缺一不可。

## 8. 开源开放生态：六柱网络护城河

### 8.1 P1–P6 飞轮

在知识平权、能力平权、AI Coding 时代，传统"代码闭源 + 销售垄断"的护城河正在瓦解。新护城河 = **开放网络正反馈**：

```
P1 生态引力              （开源社区贡献者指数增长）
  ↓
P3 协同进化              （社区贡献 → 产品进步 → 吸引更多贡献）
  ↓
P4 标准话语权            （主导开放协议 / API / 本体规范）
  ↓
P5 人才磁场              （核心贡献者被社区认可 → 慕名加入）
  ↓
P2 信任主权 (= Z 轴)     （Apache 2.0 全开源 → 无需商业许可跑满能力）
  ↓
P6 共识飞轮              （品牌信任 + 治理透明 → 扩大生态引力 → 回 P1）
  ↓
↺（飞轮自加速）
```

### 8.2 Open Core 治理模型

| 组件 | 开源策略 | 说明 |
| --- | --- | --- |
| **核心运行时**（Runtime） | Apache 2.0 全开源 | Agent 引擎、网关、UNS、经验库、蓝弧 |
| **Agent 阵容** | Apache 2.0 全开源 | V1 11 + W1-W4 9 = 20 Agents / 65 MCP 工具 |
| **四协议网关** | Apache 2.0 全开源 | Modbus/MQTT/OPC-UA/IPC-CFX |
| **知识图谱/本体** | Apache 2.0 全开源 | 本体不可闭源（否则违背信任主权） |
| **托管运行时** | 闭源转开源评估中 | 云管控、多租户编排 |
| **行业 Agent 包** | 商业许可 | 垂直行业深度定制（半导体、汽车、锂电……） |

"开源"不是免费代名词，而是信任基础设施。客户不需要相信智衍的承诺——只需要检查 Apache 2.0 许可下的代码，就知道数据主权在自己手中。

## 9. 价值观与方法论：认知操作系统

### 9.1 认知纪律（对抗两种盲区）

**护短盲**（对自己）—— 不自夸当下；当前二十强垫底是事实，天花板居首梯队也是事实。差异化是生存之本，不自欺。

**恐怖盲**（对巨头）—— 级别高 ≠ 领先（看原生度 D7，retrofit 含 legacy）；方向被巨头验证 = 利好，非威胁；竞争评估须双盲检（护短盲 + 恐惧盲同时检查）。

两者同时存在且都可能发生时，"事实与反应分离"是第一纪律。

### 9.2 五条认知铁律

1. **不被现象迷惑**："Palantir 级别高" ≠ "Palantir 领先"——看原生度 D7 而非市值/客户数。
2. **方向被验证 = 利好**：如果微软/NVIDIA 也在推工业智能体，说明赛道被证实，不是智衍走错了。
3. **竞争评估双盲检**：先用护短盲检一遍（是否低估了自己），再用恐惧盲检一遍（是否高估了对手）。
4. **楔子定位**：不抢"工厂大脑"这个战场（OT 安全/功能安全认证/物理硬件——巨头主场不可硬刚），只攻(1)经营层隐性决策、(2)中国根区域、「(3)SME & 联盟轻量入口。
5. **人 holon 终审**：任何关于人类角色的自动决策，必须留人类在环——这是三主义闭环中行为主义最后"人审"的伦理边界。
