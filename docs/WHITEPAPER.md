## 执行摘要

制造业正从「工业 4.0 的自动化」迈向「工业 5.0 的人机协作与韧性」。在这一进程中，企业最大的痛点不是「没有数据」，而是**数据散落在 PLC、SCADA、MES、ERP 的孤岛中，无法被实时理解、规划和执行**。

智衍 EvolvIQ 是一个 **AI 原生的工业智能体开发与部署平台**。它把 20 类高频工业场景——研发、供应链、制造、质量、经营决策——封装为可直接调用的自治 Agent，通过统一网关接入 Modbus / MQTT / OPC-UA / IPC-CFX 四类工业协议，配合跨 Agent 知识图谱与「按效果调参」的授权引擎，实现 **感知—规划—执行—复盘** 的闭环。

**三个核心差异化**：

1. **Agent 即产品**：每个工业能力是一个独立可验证的 Agent（确定性算法 + LLM 规划层），不是「一个大模型套提示词」。
2. **韧性降级**：任何外部依赖（数据库 / 知识图谱 / 网关）不可达时自动回退到本地替代，系统永不崩溃。
3. **授权护栏**：每个 Agent 有独立授权边界，高风险动作必须人类确认，平台「自治但有界」。

**实测结论**：生产实例真实跑通，`pytest` **51 项全过**；端到端实测中供应链齐套率从 **41.7% 自动提升到 100%**、能耗碳排识别 **4 项降碳机会并算出投资回收期**。平台实用性评级 **7.5 / 10**，属于「高保真行业原型 / 准生产系统」。

**使用门槛**：硬件环境门槛极低（一台普通云服务器 + Docker）；真正释放价值的两个前提——① 一个 LLM API Key，② 至少一条可对接的真实数据源（OPC-UA / MQTT 最常见）。

## 第一章 背景与平台定位

### 1.1 工业 5.0 下的新需求

工业 4.0 解决了「设备互联与数据采集」，但遗留了三个未解难题：

- **理解断层**：数据被采集了，但缺乏能把它翻译成「该做什么决策」的认知层。
- **执行断层**：分析报告躺在看板上，没有人把它变成产线上的实际动作。
- **韧性断层**：系统强依赖某个数据库或网关，一旦宕机全链瘫痪。

工业 5.0 强调「以人为本、可持续、韧性」。智衍 EvolvIQ 的设计哲学正是回应这三点：**让 AI Agent 成为人类工程师的协作者（而非替代者），在可持续与韧性约束下主动执行**。

### 1.2 平台定位

智衍 EvolvIQ 不是「低代码平台」、不是「BI 看板」、也不是「单一预测模型」。它的定位是：

> **制造业的「工业智能体操作系统」——上层是 20 个面向场景的自治 Agent，下层是统一的数据接入网关与授权引擎，中间是跨 Agent 可溯源的知识网络。**

## 第二章 系统架构与核心设计理念

### 2.1 四层架构

| 层 | 职责 | 关键组件 |
|----|------|---------|
| 接入层 | 工业协议接入与归一化 | 4 类网关（OPC-UA/MQTT/Modbus/IPC-CFX） |
| 能力层 | 工具与算法原子化 | 65 个 MCP 联邦工具 |
| 智能层 | Agent 规划与执行 | 20 个 Agent + LLM 规划层 + 知识图谱 |
| 治理层 | 授权、租户、审计 | 授权引擎 + 多租户 + 审计日志 |

### 2.2 核心设计理念

#### 理念一：Agent 即产品（Algorithm + LLM）

每个 Agent 由「确定性算法内核 + LLM 规划外壳」组成。算法内核负责真算（如齐套率、产能负荷、碳核算），LLM 负责把自然语言目标拆解成步骤、调用工具、组织结论。**这保证了结论可复现、可审计，而不是大模型的随机幻觉。**

#### 理念二：韧性降级（Resilience Degradation）

这是平台最关键的工程决策。任何外部依赖不可达时自动回退：

| 依赖 | 正常 | 降级 | 影响 |
|------|------|------|------|
| PostgreSQL | 持久化 | SQLite | 无感知 |
| Neo4j | 知识图谱 | 内存邻接表 | 图谱分析降级，核心可用 |
| 工业网关 | 真实源 | simulated 模拟 | 演示不间断 |
| LLM 通道 | 主模型 | 备用通道 | 规划降级 |

**价值**：系统永不因单点故障整体宕机，部署与演示风险极低。

#### 理念三：授权护栏（Authorization Guardrail）

每个 Agent 有独立授权边界（`confidence_threshold` / `max_daily_autonomous` / 人类介入队列）。低风险动作自主执行，高风险动作进人工确认队列。**平台「自治但有界」，符合制造业对「安全可控」的硬性要求。**

#### 理念四：知识图谱可追溯

跨 Agent 知识图谱记录「决策—依据—结果」的链路，使每一次 Agent 输出都可被溯源、被复盘，支撑持续改进与合规审计。

## 第四章 数据接入与协议网关

### 4.1 三层数据接入能力

| 层 | 方式 | 说明 |
|----|------|------|
| 协议网关 | OPC-UA / MQTT / Modbus / IPC-CFX | 直连设备与产线，实时数据 |
| MCP 联邦 | 65 工具经 HTTP / stdio 暴露 | 上层 Agent 与外部系统调用 |
| 业务数据层 | 种子 JSON / PostgreSQL / 改写 `tools.py` | 接 MES / ERP 业务数据 |

### 4.2 四类协议 × 真实产品对接矩阵

| 协议 | 接口方式（代码已验证） | 常用产品是否提供接口 |
|:-----|:----------------------|:-------------------|
| **OPC-UA** | `opc.tcp://host:4840` + 节点读写（支持控制） | ✅ 西门子 SIMATIC / 罗克韦尔 / KEPServerEX / Ignition / WinCC —— PLC/SCADA **标配** |
| **Modbus** | `host:port`（TCP 502）+ coil/holding 读写 | ✅ 各品牌 PLC / 智能电表 / 温控器 / 变频器 —— **最普适** |
| **MQTT** | `broker:1883` + 订阅主题 / 下发 | ✅ 阿里云 IoT / 华为云 IoT / ThingsBoard / EMQX |
| **IPC-CFX** | AMQP 总线 + `CFX.*` 事件 | ✅ ASM / Kohyoung / Yamaha SMT 设备 + CFX/Hermes MES —— **电子/SMT 专属** |

> **结论**：协议层「工业标准全覆盖」，不存在「产品接不进」的问题。现代 PLC/SCADA 原生提供 OPC-UA；Modbus 几乎什么设备都有；MQTT 是 IoT 平台标配。**真正的工作量在「节点地址 / topic 命名 / 字段对齐」的映射，不在协议本身。**

### 4.3 渐进式对接策略

韧性降级允许企业「先 simulated 演示 → 接一个真实源验证 → 逐步扩展」，无需一次性全量接入。对 90% 制造企业，**OPC-UA（产线）+ MQTT（IoT 平台）** 两条线 1 周内即可见到实时数据驱动的分析。

## 第五章 部署架构与运行前提

### 5.1 三种部署形态

| 形态 | 适用 | 复杂度 |
|------|------|------|
| 本地 Python（自动降级） | 试用 / 开发 | 极低 |
| Docker 一键（PG+Neo4j+前端） | 演示 / 中小部署 | 低 |
| 私有化集群（多租户） | 企业 / 集团 | 中 |

### 5.2 分层前提条件

**最低门槛（零数据即跑）**：`data/seed/` 内置 17 个半导体风格真实数据文件，开箱即演示全套能力。

**实用门槛（释放真实价值）**：① 一个 LLM API Key；② 至少一条可对接的真实数据源。

### 5.3 硬件与环境

| 项 | 最低（演示） | 推荐（生产） |
|----|------------|------------|
| CPU | 4 核 | 8 核 |
| 内存 | 8 GB | 16 GB |
| 存储 | 20 GB | 50 GB |
| 软件 | Python ≥3.13 / Node 22 / Docker | 同左 |
| 出网 | 拉镜像 + 访问 LLM | 同左 |
| 对外端口 | 仅 3006（studio） | 同左 |

> 内存大户是 Neo4j（2–4G）与 RabbitMQ（1–2G）；不需要知识图谱可设空 `NEO4J_URI` 直接省掉。

### 5.4 多租户

内置完整多租户：数据按 `tenant_id` 行级隔离，未带密钥自动归属默认租户。认证用 `X-Tenant-Key` 请求头，支持自助注册、密钥轮换、租户级网关覆写。

## 第六章 典型应用场景

### 场景一：半导体封测厂 · 缺料止损

**痛点**：BOM 物料分散在多家供应商，缺料往往在投产前才暴露，导致停线。
**智衍动作**：`supply_chain` Agent 自动跑齐套检查 → 识别 6 项缺料风险 → 给出国产替代方案 → 齐套率从 **41.7% 提升到 100%**，交期准时率 75%→91.7%。
**价值**：避免一次停线即可回收全年平台投入。

### 场景二：SMT 电子厂 · 降碳合规

**痛点**：ESG 报告靠人工统计，碳排来源不清，降碳投资无依据。
**智衍动作**：`energy_carbon` Agent 核算周能耗 18.2 万 kWh、碳排 86t → 识别 4 项降碳机会 → 算出空压机改造回收期 1.8 年 / 投资 65 万。
**价值**：用真实 ROI 支撑节能投资决策，满足客户 ESG 审核。

### 场景三：多工厂集团 · 经营驾驶舱

**痛点**：各厂数据孤立，集团经营会靠 PPT 拼凑，滞后 2 周。
**智衍动作**：`executive_cockpit` 聚合营收 / 毛利 / 预算执行 / 产出完成率，实时呈现超预算部门与风险项目；`demand_order` 做 S&OP 再平衡。
**价值**：经营决策从「月度复盘」变为「周级敏捷」。
