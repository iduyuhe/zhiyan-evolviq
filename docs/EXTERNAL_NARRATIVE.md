## 0. 一句话定位（经批准的电梯陈述）

> 智衍是一套**工业智能体平台**，为企业经营管控者与一线执行者提供**智能分身（决策孪生）**——把散落在 ERP/MES/设备/市场里的数据，实时凝练成可执行的经营判断。我们不推倒你已有的系统，而是在其上叠加一个"实时决策脑 + 全息真相源"。

- 关键词顺序固定：**工业智能体平台 → 决策孪生 / 智能分身 → 叠加而非替换 → 实时决策**。
- 不得把"决策孪生"与"几何/物理数字孪生"混为一谈（见 §10 政策对接）。

## 2. 四层分身框架（与三圈解锁对齐）

| 层级 | 对外命名 | 解决什么 | 对应 G 模式圈层 | 集成要求 |
|---|---|---|---|---|
| 产业级 | 产业决策分身 | 全球价值链 / 宏观走势 | 外圈（零集成，免费） | 仅公开源声明式 |
| 行业级 | 行业洞察分身 | 同行对标 / 标杆参照 | 外圈（声明式） | 声明式现状描述 |
| 企业级 | 经营管控分身 | 经营驾驶舱 / 跨域决策 | 中圈（接 1 源起） | 接入客户数据 |
| 专业级 | 岗位执行分身 | 设备 / 工艺 / 工序 | 内圈（私有化） | 深度集成 |

**护城河表述**：四层贯通**同一套知识资产**，Agent 可跨层下钻——从一颗芯片的全球供需，一路钻到一条产线的换线预案。这是"平台"而非"单点工具"的根本差异。

## 3. 成熟度模型 L0–L3（含红线）

- **L0 观察**：采集与呈现，不给建议。
- **L1 判断**：给出"发生了什么 / 意味着什么"。
- **L2 预案**：给出"可以怎么做"（备选方案 + 权衡）。
- **L3 授权执行**：在限定边界内自动执行回写。

🔴 **红线**：
1. 今日对外**只承诺 L0–L2**，绝不承诺 L3。
2. 分身**不得代签、不得代拍板**——凡涉对外责任动作，**人留终审**。
3. 任何"授权执行"必须显式标注授权边界与人工复核点，不得暗示"全自动"。

## 4. 角色 — 技能 — 权限 绑定模型

- **技能挂在"角色分身"上（1:N）**；权限是技能的**副产品**（授权等级 L0–L3），不是独立配置。
- **Agent ≠ 技能**：Agent 是实现载体，中间必须有映射层。对外只讲"分身能做什么技能"，不堆 Agent 数量。
- 🔴 **技能库从真实终审记录中长出**：先有真实采纳/否决轨迹，再沉淀为技能；**严禁一次性列 200 条预设技能**（虚假丰满）。

## 5. 人类反馈闭环（三态铁律 + 双裁判）

- **三态**：采纳 = 正样本；否决 = 负样本（**必须附归因四选一**：误判 / 过时 / 越权 / 不适配）；沉默 ≠ 采纳（不得把"没说话"当好评）。
- **双裁判**：人管"可接受性"（愿不愿用），事实 KPI 管"正确性"（准不准）。二者独立。
- 🔴 **采纳率禁止上考核**——避免为刷指标诱导采纳，污染资产。

## 6. 注册即入职（G 模式 + 成本结构）

标准路径（首屏预生成 TTFV < 60s）：
**注册 → 选角色 → 装技能 → 导出权限 → 分配四层视角 → 首屏预生成**。

- 成本结构：**宏观免费、微观付费**。外圈（产业/行业级）免费清晰，内圈（企业/专业级集成）是稀缺付费点。
- 对外叙事重点：**注册即有获得感**，不先谈价钱、不先走招投标。

## 7. 开放系统世界观

- 系统是**开放**的，不封闭。
- 宝库 / 预设库 = **开放获取加速层**（让你更快起步），不是封闭库存。
- 决策重心在**内部**：外部信息免费且清晰，内部数据稀缺且关键——价值来自"外部清晰 + 内部贯通"的化合，而非囤数据。

## 8. "第一手信息"口径

🔴 **"第一手信息" = 公开源第一时间 + 第一解读 + 跨源串联**。
- 严禁表述为"独家""内幕""我们提前知道"。
- 半导体等行业**尤敏感**：对外仅做公开信息的及时整合与跨源串联，不做任何未公开判断。

## 9. 对外口径铁律清单（Do / Don't）

**必须做（Do）**
- 用"叠加实时决策脑"替代"替代 ERP/MES"。
- 用"平台承载 N 个场景智能体"解释规模（25 个 Agent ≠ 全省 300 总量，讲清承载逻辑）。
- 主动披露诚实缺口（见 §11），把"坦诚"变成信任资产。

**严禁做（Don't）**
- 不承诺 L3、不暗示全自动、不让分身代签。
- 不用"董事长助理 / 数字员工"等替身隐喻。
- 不夸大"天生带数据"；宝库尚小，如实说"开放获取加速层"。
- 不把内部真名案例（real_anchor）对外泄露——对外一律匿名（见 §12 零真名）。

## 10. 政策对接叙事（以浙江《AI 赋能制造业》方案为例）

- **工业智能体 = 强对齐**：25+ 自研 Agent + 多 Agent 编排器 + 统一命名空间（UNS），正踩政策靶心，可直接对外定位"工业智能体平台"。
- **决策孪生 = 互补叙事**：政策讲"数字孪生（几何/物理）"，智衍讲"**决策层孪生 / 经营管控数字分身**"——界定为"决策层孪生"形成互补，而非硬蹭物理孪生。
- **不造模型 = 诚实短板**：用模型不造模型，缺垂类/边缘/MaaS/幻觉治理系统性证据；但**预设库 + 案例库 = 天然高质量行业数据集**，是隐性政策资产，可对接"高质量行业数据集"红利。
- **获客哲学差异**：政策是"自上而下示范+补贴+招投标"；智衍是"自下而上 G 模式免费外圈、跳过招投标"。二者在"中小企业普惠 / 小快轻准"方向一致，建议把 G 模式包装成政策语言（**零门槛普惠 / 效果付费**）。

## 16. 设计原则：创建时 AI 辅助 / 运行时确定性（HubPort 启发）

> 吸收自公开研究的 AI 原生物联网接入平台 HubPort（南向接入层）核心范式，与本项目"决策大脑"互补不竞争。**本原则仅约束我们对"接入 / 脚手架"类能力的设计，不约束决策 Agent 本身。**

- **创建时 AI 辅助（lower the bar）**：让贡献者丢一份接口文档或一句自然语言描述，AI 辅助生成适配器骨架、字段映射草稿、连接器探测模板——把"周级接入"压到"分钟级起草"，降低社区与现场接入门槛。
- **运行时确定性（keep the contract）**：无论骨架是否由 AI 生成，运行态必须是**确定性**的——固定输出契约（字段 / 形状 / 单位不变）、超时 / 不可达异常显式、可单测、可审计。AI 只生成"初稿代码"，不生成"运行时行为"。
- **边界红线**：
  1. AI 不得"假装连通 / 假装达标"——任何"连通成功""契约通过"必须来自真实握手或真实契约测试，不得由 AI 推断。
  2. 对外字段形状由契约测试死守，不得因 AI 生成而漂移（见 §9 不夸大、§11 诚实缺口）。
  3. 本原则与"不造模型"（§11）一致：专注决策层编排与接入加速，模型 / 协议细节开放接入、AI 辅助生成。
- **对外话术**：讲"AI 辅助接入脚手架，运行态确定性可审计"，不讲"AI 自动搞定一切"。
