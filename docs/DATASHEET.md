# 智衍 EvolvIQ · 一页纸产品规格与竞品对比

> **定位**：面向电子制造 / 半导体行业的 **AI 原生工业智能体开发与部署平台**——把 20 个行业 Agent、65+ MCP 工具、4 类工业协议网关与授权护栏，封装成一套可演示、可部署、可扩展的「工业智能体操作系统」。

---

## 一、核心规格（一页纸）

| 项目 | 规格 |
|------|------|
| **产品形态** | 开源平台（Apache-2.0）+ 托管/企业版可选 |
| **智能体规模** | 20 个行业 Agent（研发×2 / 制造×12 / 经营×6） |
| **工具能力** | 65+ MCP 工具（federation，命名空间 `agent__method`） |
| **工业协议** | Modbus · MQTT · OPC-UA · IPC-CFX（含韧性降级 simulated） |
| **授权护栏** | 置信度阈值 + 每日自主上限 + 人工审批边界 + 多租户作用域 |
| **知识图谱** | 跨 Agent 知识图谱（Neo4j，内存图回退） |
| **前端** | React + TypeScript + Vite + Tailwind（控制台 / 结果视图 / 策略调参） |
| **后端** | FastAPI + Pydantic v2 + 韧性降级（PG→SQLite / Neo4j→内存） |
| **LLM** | DeepSeek / 混元（可切换，API Key 驱动） |
| **部署** | Docker Compose（10 服务）/ 单机 8C16G 起 / 仅暴露 3006 |
| **数据前提** | 零数据可演示（内置种子）；实用需对接 1 个真实 MES/ERP 源 |
| **测试** | pytest 51 passed / 0 failed；CI 自动 pytest+tsc+docker |
| **语言** | 中文（主）/ 英文 README + GUIDE + CONTRIBUTING |
| **许可证** | Apache-2.0 |

## 二、20 个 Agent 能力一览（按三层）

**研发层（2）**：`rd_npi`（新品导入）· `dfm_check`（可制造性设计）
**制造层（12）**：`supply_chain`（供应链齐套）· `bom_selector`（BOM 优选）· `oee_optimizer`（设备综合效率）· `smt_changeover`（换线优化）· `eco_change`（工程变更）· `pm_maintenance`（预测性维护）· `yield_analysis`（良率分析）· `quality_trace`（质量追溯）· `aoi_judge`（AOI 判读）· `ipc_standard`（IPC 标准）· `demand_order`（需求订单）· `wms_logistics`（仓储物流）
**经营层（6）**：`aps_scheduler`（排程）· `energy_carbon`（能源碳）· `cost_analysis`（成本）· `compliance_q`（合规问答）· `executive_cockpit`（经营驾驶舱）· `procurement_manage`（采购管理）

## 三、竞品对比（诚实视角）

| 维度 | **智衍 EvolvIQ** | 传统 MES（SAP ME / 西门子 Opcenter） | 低代码平台（织信 / 简道云） | 通用 Agent 框架（LangChain / AutoGen / CrewAI） |
|------|----------------|--------------------------------------|------------------------------|----------------------------------------------|
| **定位** | 工业领域智能体 OS | 制造执行系统 | 通用应用搭建 | 通用 LLM 编排 |
| **AI 原生** | ✅ 原生设计 | ⚠️ 多为后加 BI | ❌ 弱 | ✅ 但无领域 |
| **工业协议** | ✅ 4 类原生网关 | ✅ 强（PLC/SCADA） | ❌ 需另接 | ❌ 无 |
| **领域算法** | ✅ 20 行业 Agent 真算 | ✅ 深但固定 | ❌ 无 | ❌ 无 |
| **部署重量** | 轻（Docker / 8C16G） | 重（数月实施） | 轻（SaaS） | 轻（库） |
| **授权护栏** | ✅ 内置置信度/审批 | ✅ 权限体系 | ✅ 角色 | ❌ 需自搭 |
| **韧性降级** | ✅ 外部依赖不可达自动回退 | ✅ 高可用 | ✅ 云可用 | ❌ 依赖调用方 |
| **灵活扩展** | ✅ 加 Agent 8 步接线 | ❌ 改造成本高 | ✅ 搭表单 | ✅ 写代码 |
| **实时数据** | ⚠️ 种子开箱，接真源 1–2 周 | ✅ 原生实时 | ⚠️ 靠 API | ⚠️ 靠工具 |
| **多 Agent 编排** | ❌ 当前各自为战 | N/A | N/A | ✅ 强 |
| **上手门槛** | 中（需 IT 接数据） | 高（实施重） | 低（业务自助） | 高（开发） |
| **最适合** | POC / 培训 / 咨询货架 / 开源切入 | 大型工厂精细执行 | 内部轻应用 | 通用 AI 原型 |

**一句话判断**：
- 要**精细执行 + 强合规**的大型工厂 → 传统 MES 仍是底座。
- 要**快速搭内部轻应用** → 低代码更快。
- 要**通用 AI 编排实验** → LangChain 系更灵活。
- 要**工业领域 AI 分析能力 + 可演示 + 可扩展底座** → 智衍 EvolvIQ 是当前最贴合的开源选择。

## 四、价值杠杆（ROI 框架）

```
数据接入（1–2 周/源）  →  20 Agent 量化分析  →  授权内自主执行  →  经营指标改善
        ↑ 唯一卡点               ↑ 开箱即用                ↑ 护栏保障安全
```

实测杠杆案例（生产实例）：供应链齐套率 **41.7% → 100%**；周能耗 **18.2 万 kWh** 识别 4 项降碳机会（回收期 1.8 年/投资 65 万）；需求订单再平衡授权内自动执行。
