### 0. 为什么需要"科学"呈现

此前两份图谱（竞争力六柱、成熟度三轴）是定性框架，各有洞见但**没有统一量纲**，无法回答三个最关键的问题：

1. **竞争力到底谁强**？（横向可比的绝对值）
2. **自主可控在其中起什么作用**？（不是情怀，是可量化变量）
3. **发展前景（ trajectory ）谁更高**？（不是当前值，是天花板与增速）

本图谱用一套**综合竞争力指数（CCI）**把两张图收敛到一个坐标系，使三量（自主可控 / 发展前景 / 竞争力）可同时读出，并覆盖**智衍、西门子、美的、用友、金蝶、Palantir、SAP、纯 agent-native 创业**共 8 家玩家。

### 1. 综合竞争力指数 CCI 定义

在知识平权、能力平权、AI Coding 时代，护城河 = 开放网络正反馈。由此定义：

```
CCI(t) = M(t) × ( α·S + β·A + γ·N(t) )          α + β + γ = 1
```

| 符号 | 维度 | 来源 | 量纲 | 取值 |
| --- | --- | --- | --- | --- |
| **M** | 成熟度（能力闸门） | 成熟度模型 L0–L5 / 实时化率 | 0–1 | 乘法项：能力为必要不充分 |
| **S** | 原生度（演进阶段） | AI / AI+ / AI-native | 0–1 | 决定天花板与轨迹 |
| **A** | 自主可控度（Z 轴） | 闭源云 / 闭源本地 / 信创半开放 / Apache 全开源 | 0–1 | 客户自由度、脱绑能力 |
| **N** | 网络引力 | 六柱 P1+P3+P4+P5+P6 复合 | 0–1 | 平权时代主护城河 |
| α,β,γ | 权重 | 见 §2 | — | α=0.30, β=0.35, γ=0.35 |

**建模逻辑（可辩护）**：
- **M 作乘法闸门**：没有真实能力（M→0），网络/自主皆空谈——能力是必要不充分条件。
- **A 权重最高（β=0.35）**：自主可控是客户自由度的硬标尺，也是巨头结构性软肋（见 §5 敏感性）。
- **N 权重最高并列（γ=0.35）**：平权时代护城河主源是开放网络（Metcalfe 定律类比）。
- **S 权重 0.30**：原生度决定轨迹与天花板，但不直接产生当下价值。

#### 1.1 模型自洽性约束（v2 修正）

- **上限约束**：由于 `α+β+γ=1` 且 S,A,N∈[0,1]，有 `(αS+βA+γN) ≤ 1`，故 **CCI(t) ≤ M(t)**。这是数学硬约束——任何"天花板"估值都不得超过该玩家成熟度的理论上限，否则模型不自洽。
- **演化假设（可复核）**：
  - `M(t) = M0 + (M_top − M0)·t/3`（三年线性爬坡到能力上限 M_top）
  - `N(t)` 按开放度复利：`N(t) = N0 × r^N` —— 开放(A=1.0) `r=1.40`；信创半开放(A≈0.3–0.4) `r=1.12`；闭源 `r=1.03`
  - `S, A` 恒定（原生度是架构属性、自主可控受 legacy 锁死，三年难变）
- **含义**：智衍当前 M 低，但 M_top 高（native 落地快）+ N 强复利，是天花板来源；巨头 M_top 接近封顶、N 仅微增，天花板被钉死。

### 3. 三量合一：气泡定位图（图 1）

- **X 轴 = 成熟度 M**（当前能力位置）
- **Y 轴 = 原生度 S**（发展前景 / 天花板高度）
- **气泡大小 = 竞争力 CCI**（当前绝对竞争力）
- **气泡颜色 = 自主可控度 A**（深蓝=开源自主，深红=闭源锁定，橙=信创半开放）

读图结论：
- **西门子 / 美的 / Palantir** 居右（M 高）、气泡大（CCI 高），但**颜色深红**（A 极低）→ 当前强、自由度弱、被锁定；Palantir 虽 Y 较高（S=0.75）但仍深红。
- **用友 / 金蝶** 橙色调（A=0.35/0.30，信创自主叙事）→ 在"自主可控"维度上明显优于外资闭源巨头，是国产替代的结构性红利。
- **智衍** 在最顶（S=1.0），气泡中等（CCI 当前第六），**颜色最深蓝**（A=1.0）→ 当前非最强，但站在"原生度天花板 + 完全自主可控"双顶上。
- **SAP** 沉底红（M 低、S 极低）；**创业** 顶但小（S=1 但 M/CCI 低）。

**核心科学结论**：
- **当前排名**：西门子(0.438) > 美的(0.399) > 用友(0.375) > Palantir(0.362) > 金蝶(0.325) > 智衍(0.221) > 创业(0.154) > SAP(0.072)。（诚实承认智衍现在不是最强）

### 6. 稳健性与敏感性

- **权重敏感性**：即便 α/β/γ 在合理区间重标，结论"智衍天花板 > 巨头"**不变**——它来自结构性事实（A、S 已顶满 + N 可复利），非权重偶然。仅"赶超年份"在 2.2–2.9 年间浮动。
- **A 的单变量弹性**：闭源巨头（含 Palantir）若想靠"提升 A"自救，受 legacy / 硬件 / 军工许可锁死，**边际成本极高、几乎不可行**；智衍则 pre-committed A=1.0，无此包袱。用友/金蝶的 A 提升依赖政策驱动的"信创开源"，天花板有限。
- **最大风险变量**：智衍的 N（网络引力）。模型成立前提是"开放网络真能复利"——这要求执行 Open Core 治理（开框架/本体/协议，留运行时/行业包），见 `OPEN_SOURCE_COMPETITIVENESS_MAP.md` §5。
- **模型边界**：本模型不捕捉"资金碾压单年砸穿 M"的极端情形（如巨头一年并购补 M）；但即便 M 封顶，巨头仍受 A、S 双重封顶，结论结构不变。

### 7. 对智衍的战略含义

1. **不自夸当下，敢言天花板**：对外话术从"我们最强"转为"我们当前第六，但天花板第一，且完全自主可控"——符合 `VALUES_AND_METHODOLOGY.md`"实事求是 / 不被现象迷惑"。
2. **自主可控是楔子而非装饰**：Z 轴（A）是外资闭源巨头（西门子/美的/Palantir）系统性塌方处；**用友/金蝶借信创把 A 抬到中段，反而证明"自主可控"是企业真实痛点与可兑现维度**——智衍以 Apache 全开源把 A 顶到满格，差异化最锐。
3. **网络引力是唯一正确赌注**：在平权时代，小玩家对抗资金/数据/认证的**唯一杠杆是 N**——集中资源建开放生态，而非补 M 到巨头水平。
4. **路线锁定**：born-native + Apache-2.0 不是道德选择，是 CCI 模型下的**最高杠杆结构选择**；Palantir 的"AI 原生但极闭源"恰好反证——S 高也救不了被 A 封顶的结局。

---

### 8. 结论一句话

> 在平权时代，**竞争力 = 能力 ×（原生度 + 自主可控 + 网络引力）**。8 家玩家中，外资闭源巨头当前值高但被"闭源 + retrofit"双重封顶；国产 ERP 双雄借信创把自主可控抬到中段、紧追巨头天花板；Palantir 虽 AI 原生却因极闭源被钉死；智衍以满格的自主可控与原生度，把唯一可复利的"网络引力"变成发展前景的主引擎——这是可量化、可复核、结构性的不对称优势。
