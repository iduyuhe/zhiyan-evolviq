### F. 设计思想升级：环境感知——第⑥路（2026-07-27 杜总提出；✅ **已毕业进路线图**）

> **状态（2026-07-27）**：杜总拍板采纳。已正式写入 `STRATEGY_SYSTEM_ROADMAP.md`（六路感知，§1.2/§3.1/§3.2/§3.3/§4.1/§4.2/§5.1）与 `PRODUCT_DEVELOPMENT_PLAN.md`（v30 落点）；落实计划+系统影响分析见 **`ENVIRONMENT_PERCEPTION_PLAN.md`**（α最小验证→β租户自定义筛选→γ智能推荐三阶段）。本节保留为设计思想的讨论存档。

> **缘起**：讨论社交通道时杜总的启发——"对企业来讲，无论是产品研发还是市场战略以及企业战略，都需要这个感知系统。我们的系统应该不仅感知企业内部，还应该感知对企业有影响的外部信息。**从一个封闭的系统变成一个真正的物理世界的系统。**"

- **现状确认**：五路感知（①网关/IIoT ②外部系统 ③人 ④社交 ⑤会议协作）中，"②外部系统"实指 ERP/MES/PLM/WMS——仍是**企业围墙内**的 IT 系统。五路全部朝内，系统对企业边界之外的物理世界是**盲的**。
- **F1 新增第⑥路「环境感知」（environment）**：感知对企业有影响的外部世界信号——
  - 政策法规（行业新规、环保/安全标准变更）
  - 市场与行情（原材料价格、汇率、需求指数）
  - 竞品与技术趋势（竞品发布、专利、开源动态）
  - 供应链上游风险（供应商所在地事件、物流中断、地缘因素）
  - 客户公开声音（公告、招标、行业媒体）
- **F2 架构上完全复用既有骨架**：环境信号 → UNS 新增 `environment` 路 → 显性/隐性捕获（抽取即锚定，来源+可信度分级标注）→ 全息真相源 → agent 决策引用。不推倒任何东西，是五路→六路的自然生长。
- **F3 战略意义**：
  - 决策实时化率的覆盖面从**车间级**（排产/换线/能耗）拉升到**战略级**（研发方向、市场策略、供应链布局）——北极星指标的分母变大、价值变厚。
  - 对外叙事再升一级：Palantir 是静态符号地图，智衍是"活循环"；加上环境感知后，是**开放系统的活循环**——企业作为物理世界中的生命体，同时感知体内（五路）与体外（第⑥路）。
  - "原生全息沉淀权"补上最后一块：企业的真相不止在围墙内，**影响企业命运的外部事实同样是真相源的一部分**。
- **F4 可信治理机制（2026-07-27 杜总定调，从"边界建议"升级为"产品机制"）**：
  - **官方可信源为锚（第一性原则）**：来源可信度分级以"**可信、关键、官方**"为最高锚点——官方发布（政府/监管/标准机构/交易所）> 权威媒体/行业协会 > 一般网络。官方源信号可直接锚定进真相源；非官方源**一律必须经过筛选**才能进入。
  - **筛选规则客户自定义**：哪些渠道可接、各渠道可信度权重、过滤关键词/主题、准入阈值——全部开放给租户在配置界面自行定义（复用"数据源先测试后保存"的配置 UI 范式）。系统给默认模板，客户按自身行业与风险偏好调整。
  - **智能推荐**：系统在客户自定义之上叠加智能层——①根据租户行业/物料/供应商画像**推荐值得订阅的信息源**；②对已接入信号做**相关性打分**（与本企业产品、供应链、市场的关联度），高相关优先推送给对应 agent，低相关自动降噪；③推荐结果本身可被客户采纳/驳回，驳回行为反哺推荐模型（与蓝弧后果回流同构）。
  - 低可信度/低相关信号进 `_needs_review` 审批流（复用邮件通道机制），人审通过才锚定。
  - 合规红线：只接**公开合法渠道**（RSS / 官方公告 / 行情 API / 政策库），不爬取受限内容，不碰个人隐私。与"社交通道不碰公网社交媒体"的边界不冲突——环境感知是独立一路，接的是公开信息源而非社交账号。
  - 成本控制：外部源接入优先选免费/低成本公开 API，按租户可配置开关。
- **依赖**：先在本讨论稿定调（是否采纳为正式设计思想、优先级排在哪），采纳后需回写 `STRATEGY_SYSTEM_ROADMAP.md`（五路→六路）并规划最小落地版本。**不阻塞 A/C/D，可与 B/E 并行进入讨论。**

### G. 商业模式设计：「外感知先行」获客楔子（2026-07-27 杜总提出，待定调）

> **缘起**：杜总——"这个对外感知其实也是我们的一个销售员。可以让企业先用这个系统直接知道我们这个系统的价值，从外部导入内部，这可以作为一种商业模式设计。"

- **G1 模式本质**：把环境感知（第⑥路）从"平台功能"升级为"**获客楔子产品**"（wedge product / PLG 产品驱动增长范式，对标：HubSpot 免费 CRM 带动全家桶、飞书文档带动飞书全套）。产品自己完成第一轮销售——外感知轻量版让企业**零风险体验智衍的决策价值**，再沿信任爬梯导入内部全平台。
- **G2 四级信任爬梯（外部导入内部）**：
  - ① **免费外感知（SaaS 订阅）**：政策/行情/竞品信号 + agent 解读。零部署、不进内网、不碰企业数据 → 试用心理门槛≈0，当天见效。
  - ② **价值体验**：差异化在"情报→决策"——不是资讯列表，而是 agent 回答"这条政策/这轮涨价**对你意味着什么、建议做什么**"。
  - ③ **接入第 1 个内部数据源**：外部信号 × 自家数据（如原材料行情 × 自家 BOM/库存）产生**价值跳变**——"铜价涨 8%，影响你 3 个在产订单毛利，建议提前锁价"。这是从工具到平台的转化点。
  - ④ **全平台六路感知**：私有化/专有云部署，付费主体。
- **G3 结构性优势（为什么智衍做这件事恰好顺手）**：
  - 环境感知**纯出站抓取**，天然可 SaaS 化多租户运营（多租户架构已就绪），无需入站回调、不依赖 A1；
  - 与 D 首客试点互补：D 是自上而下敲门（找老板谈），G 是自下而上渗透（业务部门先用起来）；
  - 免费用户的采纳/驳回行为**反哺 γ 阶段智能推荐模型**——用户越多推荐越准，获客即数据飞轮；
  - 与路线 A 叙事自洽："从外部导入内部"正是六路感知世界观的商业化镜像，讲给客户的故事和讲给投资人的故事是同一个。
- **G4 风险与成立条件（三个前提）**：
  - **前提一：差异化必须是"情报→决策"**。行业情报/舆情监控是红海（企查查/Wind 资讯类一大堆），做成资讯工具必死；智衍的稀缺性在信号直接进 agent 决策链。①级就必须带 agent 解读，不能只推列表。
  - **前提二：设计好 ②→③ 的转化台阶**。免费 SaaS 到私有化部署跨度太大，③"接 1 个内部数据源"是必须的中间台阶（可轻量：客户上传 BOM/物料清单即可，不必接 ERP）。
  - **前提三：不另起炉灶**。外感知轻量版 = v30 α/β 同一套代码的**第二种包装**（多租户 SaaS 形态），不单独立项、不分散当前 0 首客阶段的火力。
  - 其他风险：免费用户抓取/LLM 解析成本 → 按租户限额（源数量/信号量/解读次数）；行情数据转售许可 → 首批只用公开政策库+官方指数，商业行情 API 后置。
- **待拍板**：①是否采纳为正式商业模式（写入 ECOSYSTEM_LAUNCH / 商业计划）；②外感知轻量版与 v30 α 是否合并排期（建议合并：α 做内核，SaaS 包装作 β 的一部分）；③免费额度与付费线怎么划。
