## 二、核心结论

**综合实用性评分：7.5 / 10**

一句话判断：**这不是玩具 demo，而是一套"高保真行业原型 / 准生产系统"**。
- ✅ 算法是真的（产能负荷、齐套率、碳排回收期都是真算）
- ✅ 系统是真的（生产实例活着、链路跑通、授权内自主执行在真发生）
- ⚠️ 数据是种子的（SMIC 半导体风格真实数据，但未接实时 MES/ERP）
- ⚠️ 协作是缺的（20 个 Agent 各自为战，无跨 Agent 编排）

距"实时生产级系统"的核心差距是**数据实时接入**与**多 Agent 编排**，而非算法能力。

## 四、真凭实据：生产环境真实调用产出

### 4.1 供应链 Agent（supply_chain）
目标：检查 BOM 物料齐套率并给出缺料预警和替代方案

```
齐套率 ROI 闭环：基准 41.7% → 承诺 100.0%（+58.3pp）
缺料风险项 6 → 0；交期准时率 75.0% → 91.7%
BOM: SMIC-28nm-Logic
逐物料明细：
  SI-001 8英寸抛光硅片  缺料 1703 → 0（critical→low）
  SI-002 12英寸抛光硅片 缺料 315  → 0（critical→low）
  PR-001 ArF光刻胶      缺料 0    → 0（low）
```

**判断**：真实半导体物料、真实缺料计算、真实齐套率提升——**真算**。

### 4.2 能源碳 Agent（energy_carbon）
目标：分析工厂能耗与碳排放并给出 ESG 优化建议

```
周能耗 182,000 kWh，碳排 86.0 tCO2，绿电比例 18.7%
碳强度 4.859 vs 目标 0.45（缺口 4.409）
识别降碳机会 4 项，潜在降碳 60.4 tCO2/周：
  • 空压机系统能效改造    回收期 1.8 年，投资 65 万，降碳 10.5t
  • 绿电采购比例→35%     回收期 2.5 年，投资 90 万，降碳 42.0t
  • 回流焊余热回收        回收期 2.1 年，投资 38 万，降碳 5.5t
  • LED+分区照明智控      回收期 1.2 年，投资 12 万，降碳 2.4t
```

**判断**：能耗/碳排/回收期/投资额全算出来了，**可直接进 ESG 披露看板**。

### 4.3 路由歧义观察（重要）
目标写的是"生产排程产能负荷和交期风险"，但路由命中了 **demand_order** Agent（产出需求订单分析：需求 310 万片、满足率 96.5%、2 款产品交期风险、再平衡自动执行）。

**含义**：自然语言→Agent 当前靠关键词规则（ROUTING_RULES），存在意图错配。结果仍有价值，但**用户预期与实际执行不完全对齐**——这是实用性待改进点。

## 六、实用性短板（按影响排序）

1. **数据实时性（最高优先级）**
   当前工具层从 `data/seed` 加载（SMIC 风格种子），架构上留了"可切真实 MES/ERP"接口，但**未接任何实时源**。
   → 影响：演示惊艳，但车间实时数据进不来，决策滞后。

2. **路由歧义**
   关键词规则在意图相近时错配（如 APS vs demand_order 的"交期风险"）。
   → 影响：用户说 A 做 B，降低信任。

3. **LLM 深度不足**
   分析靠"规则计算 + prompt 包装"，非真推理链（Chain-of-Thought / 工具调用规划）。
   → 影响：复杂非结构化问题（如"为什么这周良率突然掉"）答不好。

4. **多 Agent 编排缺失**
   20 个 Agent 单打独斗，无跨 Agent 协作（如"排程"应联动"供应链+设备"）。
   → 影响：经营级问题需要人肉拼接多个 Agent 输出。

5. **国际化仅文档层**
   界面全中文，英文只有 README/GUIDE。
   → 影响：海外客户/开发者上手门槛。
