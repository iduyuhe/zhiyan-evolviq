物理AI完整闭环 · 三张图

感知 · 认知 · 决策 · 执行 · 自我进化 —— 一脊 · 一体 · 四体系 · 一底座 · 五环节闭环

图一 · 五环节闭环总览

物理AI的运转流：感知（接入物理信号）→ 认知（记忆+知识图谱+技能推理）→ 决策（认知与执行之间的枢纽）→ 执行（手脚+人机协同闸门）→ 自我进化（评估信号回灌资产层）。闭环由四体系支撑，智能孪生为体，治理底座横切。决策与进化是本次补齐的两环。

图二 · 决策体系本体

决策不是新模块，而是认知与行动之间的枢纽层：输入 = 感知信号流 + 记忆（历史）+ 知识图谱/技能（关系与能力）；处理 = 情景推演 / 多目标权衡 / 约束校验（治理前置）/ 候选动作生成，且每个决策证据可追溯（事实锚点铁律）；输出 = 决策建议（给人）+ 可执行动作（交执行层）。按脊分四级：行业级情报、产业级对标、企业级运营、岗位级动作。北极星 = 决策实时化率（MVP ≥ 40%，稳态 ≥ 85%）。

图三 · 自我进化引擎（进化在资产层，不在参数层）

自我进化的燃料是评估信号：① 执行结果（反馈/成效）→ ② 评估（决策质量 / 行动效果 / 记忆准确度）→ ③ 更新四类资产（记忆 / 知识图谱 / 技能 / 策略阈值）→ ④ 回灌认知（下一轮更准）。关键判断：进化发生在 Harness 资产层（宝库、案例、预设、阈值），而非模型参数层——这正对应我们"进化单位=资产，非模型"的定位，也是工业 AGI 与通用 AGI 的根本分野。L0→L3 阶梯：静态种子 → 运行时事件积累 → 评估信号驱动更新 → 跨企业复利。
