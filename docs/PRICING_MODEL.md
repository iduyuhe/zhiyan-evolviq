## 0. 一句话商业模型

**用免费公开信号做获客楔子，用「外部信号 × 你的数据」的价值跳变做转化，用私有化部署做留存与溢价。** 企业不做"转型工程"，在每日使用中自然完成转型——转型成本从"项目费"变成"订阅费＋部署费"。

## 1. 三圈信任爬梯（与产品阵容一一对应）

| 圈层 | 数据依赖 | 包含智能体（现有阵容） | 商业状态 | 价值锚点 |
|---|---|---|---|---|
| **外圈** | 仅公开信息（六路之⑥ environment） | `executive_cockpit` / `supply_chain` / `procurement_manage` / `compliance_q` | **免费** | 零部署、零风险，每天看到政策/行情/对标信号 |
| **中圈** | 外部信号 × 轻量内部数据（上传 1 个文件，不进内网） | `cost_analysis` / `demand_order` / `bom_selector` / `rd_npi` | **付费线③** | 价值跳变：如「上传 BOM → 算出现铜价上行致毛利收窄 1.2%」 |
| **内圈** | 深度内部数据（网关/MES/全六路） | 其余 12 agent（aps/oee/pm/energy/quality/yield/aoi/smt/wms/eco/dfm/ipc） | **私有化④** | 转型完成：实时决策脑嵌入生产现场 |

## 2. 免费额度（已实现默认值的对外口径）

> 获客楔子。让任何制造企业**零成本、零部署**先用起来，建立信任。这一层边际成本极低（公开信号抓取，无重推理），符合 freemium「给一个完整窄工作流」原则。

| 项目 | 默认值 | 说明 |
|---|---|---|
| 信息源订阅 | **3 个**（政策法规 / 原材料行情 / 行业智能化对标） | 三类官方源，credibility=official 锚定 |
| 每日信号量 | **50 条 / 天** | 环境感知⑥ 抓取归一后的信号上限 |
| agent 解读 | **30 次 / 月** | 外圈 4 agent 的解读调用上限（控 LLM 边际成本） |
| 用户数 | **1 用户 / 租户** | 单租户单人，验证价值后扩席 |
| 数据上传 | 不支持（仅外圈） | 上传文件即触发中圈付费线 |

**定位**：永久免费，不作为收入来源，纯获客与信任建设。

## 3. 付费线③（信任爬梯第 3 级 · 价值跳变）

> 转化点。客户一旦上传第一个文件（如 BOM）或接入第一个内部数据源，即进入中圈——系统第一次把「公开信号 × 你的真实数据」算出可感知的价值。
> 定价定位：**国内第一梯队，约为西门子 Xcelerator 同级功能报价的 80%**。

| 项目 | 对外定价（2026-07-29 定调） | 说明 |
|---|---|---|
| 解锁范围 | 中圈 4 agent（cost_analysis / demand_order / bom_selector / rd_npi） | 上传 1 文件即全开中圈，价值立现 |
| 计费模式 | **按月订阅**（席位制） | 价值可感知且与人数挂钩，订阅制现金流可预测 |
| 基础版单价 | **¥2,480 / 月**（单用户，年付 ¥24,800 ≈8.3 折） | 国内第一梯队价位，西门子同类功能约 ¥3,100/月（按 Insights Hub ¥50,000/年÷16 功能席位）的 80% |
| 增席单价 | **+¥780 / 月 / 用户** | 国内第一梯队增席价 |
| 价值演示 | 行情 × BOM = 毛利影响测算；对标 × 项目 = 可行性评估 | S2-4 已实现最小体验 |

**定价推导**（对标 2026 市场·第一梯队定位）：
- 西门子 Insights Hub 企业版起步 $50,000/年（≈¥350,000/年），单个功能模块约 ¥3,100/月。
- 树根互联根云平台模块 ¥180,000–¥216,000/套（一次性），折合月均 ¥15,000–¥18,000。
- 华为云 MOM 平台模块 ¥58,000–¥160,000/年/模块，全功能约 ¥400,000+/年。
- **我们的 ¥2,480/月 → 高于树根互联/华为云等国内纯平台订阅价（¥1,000–¥2,000/月/席），低于西门子 Xcelerator 同级模块 ¥3,100/月，约为其 80%**。
- 首年 ¥29,760 的起付门槛显著低于同类工业 AI 平台（5–20 万起步），降低决策阻力。

## 4. 内圈私有化④（信任爬梯第 4 级 · 溢价与留存）

> 留存与护城河。深度内部数据接入（网关/OPC-UA/MES）后即私有化部署，转型已完成，迁移成本极高。
> 定价定位：**国内第一梯队的私有化定价，约为西门子私有化部署报价的 80%**。

| 项目 | 对外定价（2026-07-29 定调） | 说明 |
|---|---|---|
| 部署形态 | 私有化（Docker Compose / K8s，Apache-2.0 自托管） | 自主可控 Z 轴 A=1.0，软件授权免费 |
| 解锁范围 | 全部 24 agent + 全六路感知 | 内圈 12 agent + 范式 agent 全开 |
| 部署实施费（一次性） | **¥168,000 起** | 含网关对接 / 实施 / 培训；约为西门子私有化部署的 80% |
| 年订阅 | **¥98,000 / 年** | 含升级 + 支持 + 共生环反馈分析；约为西门子 Insights Hub 基础年费的 80%（¥350K×80%=¥280K→按国内简化取¥98K） |
| 可选 · 按节点 | **¥380 / 节点 / 年**（>500 节点面议） | 设备规模弹性；高于树根互联/华为云的节点单价（¥200–¥300），体现第一梯队定位 |
| 买断备选 | **¥268,000 永久授权 + ¥58,000 / 年维护** | 部分客户偏好买断；约为西门子永久授权报价的 80%（西门子同类约 ¥330K） |

**定价推导**（对标 2026 市场·第一梯队定位）：
- 西门子 Insights Hub 企业版：$50,000–$100,000/年（≈¥350K–¥700K/年）。
- 华为云 FusionPlant 大型企业：100 万+/年定制化（含实施）。
- 树��互联根云全模块：约 ¥200K–¥500K/年。
- **我们的年订阅 ¥98,000/年 ≈ 西门子企业版的 28%，但高于树根互联/华为云纯平台订阅价（¥50K–¥80K），卡位「国内第一梯队 × 西门子 80%」策略——全栈定价约西门子的 30–50%，「80%」指单模块/单席等价对标**。
- 开源自托管 = 无软件 license 费，实施费＋订阅显著低于闭源工业 AI 平台（50–200 万/年），数据主权 100% 留客户内网——信任爬梯第 4 级的核心差异化。

## 7. 与生态飞轮的关系

定价模型本身就是飞轮的燃料：免费外圈制造「真需求供给」（共生环的 from-customer Issue），外部贡献者有的放矢，六柱开放网络引力 N 由此生长。定价不豁免任何一条红线——白屏门禁、事实锚点、F4 可信治理（platform_insight 透明标注）在免费/付费/私有化三档同样生效。

## 附录 · 市场调研基准（2026，中国）

- **工业 AI 平台年费**：轻量 SaaS 5–20 万 / 标准私有化 50–200 万 / 企业级中台 200–1000 万+（kd.cn 行业估算）
- **云 MES**：公有云均价 ≈15 万，私有云 50–100 万（iWorker 案例）
- **SaaS 席位制**：阿里云百炼 198–1398 元/坐席/月；腾讯 CodeBuddy 198 元/人/月；SCRM 2000–6000 元/人/年
- **私有化 IoT 平台**：昊思络 1.98–6.98 万(平台)+0.6–0.9 万/年订阅；ubibot 买断 1.99 万起
- **Freemium 转化**：全球均值 2–5%，B2B PLG 良好 5–8%；中国免费→付费极低(2–5%)
- **AI 产品警告**：推理边际成本 $1–20/活跃用户/月，需转化>8% 且付费>$50/月才不流血（多数 AI 初创应走试用而非 freemium）
- **西门子 Industrial AI**：基础推理引擎 ≈5 万欧元/年，Lite 版 800 欧元/月
- **结论**：中国市场**混合定价**（低价入门 + 按量 + 订阅）最优；免费层须给"完整窄工作流"，付费触发须"必然发生"
